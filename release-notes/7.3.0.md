# TPS Global Context Menu 7.3.0 — Keep configured kind references aligned

Changing a configured kind-list path or shared-path identity through GCM now previews its dependent references alongside the affected notes. Exact GCM Navigator rules and Custom field scopes, TPS Notebook Navigator searches/hidden properties/appearances, and recognized literal Base filters move in the same source-checked transaction. Renaming a stored value on a configured list-valued Kind field carries its path references too. Shared paths only move record-specific rules with matching AND identity; generic or custom expressions that cannot be assigned safely are listed as blockers for manual review.

Global property-key migration also carries recognized Base filters, formulas, property labels and view property references, plus Notebook Navigator property keys, searches, hidden properties, sort/group settings and appearances. Custom property menus, stacked rows and native previews use authored frontmatter for the configured Kind list while keeping internal record identity separate for scopes. Health food presentation recognizes its configured classification rather than requiring a fixed `kind: food` scalar.

The feature has no built-in taxonomy values, new settings fields, background scan, or automatic repair. Writer-only changes continue to affect future records only. Markdown bodies, unrelated Base formulas, manual tags, and file names stay unchanged. The existing Rules & fields and Advanced routes remain in place; the confirmation dialog includes dependent settings references and Base files. This backward-compatible behavior addition is a minor release and requires Obsidian **1.10.0** or later.

## Validation

- Focused tests cover unique and shared kind-list paths, discriminators, list-valued Custom field scopes, authored Kind presentation, exact and ambiguous Base filters, Notebook Navigator settings, transaction/recovery guards, and Daily Note/Calendar Event templates.
- The final declared suite passed 1,519 tests with no failures. A separate production-mode build verified the byte-matched 7.3.0 artifacts in Obsidian Plugin Test Vault.
- After a Test Vault reload, a synthetic `kind: [task/todo]` note displayed `task/todo` in the stacked Kind field and its path-scoped Parents field. A synthetic `kind: [entity/food]` note displayed `entity/food` without Parents. Both QA notes were moved directly to `_archive`, and the original GCM test settings were restored byte-for-byte before another Test Vault reload.
- Test Vault validation does not establish physical-iPhone or production behavior. The public release is intended for the user's BRAT pull.
