# TPS Global Context Menu 1.22.0

## Linked-context mobile layout

- Uses the full available note width without allowing long content to widen the page.
- Tightens card spacing and padding while increasing mobile checkbox and task touch targets.
- Wraps metadata cleanly, truncates overlong source labels, and raises resting contrast on coarse pointers.

## Task context menus

- Right-clicking a task in linked context opens GCM's canonical task context menu.
- Long-pressing a task on mobile opens the same menu after 500 ms.
- Moving the pointer more than 10 pixels cancels long-press recognition, preserving native vertical scrolling.
- Context resolution uses the exact source path and one-based source line already associated with the read-only excerpt.

## Compatibility and validation

- No settings, note data, or frontmatter migration is required.
- Minimum supported Obsidian version remains 1.10.0.
- Focused linked-context service, interaction, mobile-layout, and TypeScript checks passed.
- Full declared suite and final production build were run against the isolated test-vault runtime.
- Live UI automation was skipped because the active Obsidian window was the production vault, which was not authorized for access.

This public build is ready for a user-controlled BRAT pull.
