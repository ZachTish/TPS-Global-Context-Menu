# TPS Global Context Menu 1.35.3

## Intent

Make TPS List and TPS Table task drags visibly track the pointer while preserving the existing successful drop into TPS Notebook Navigator.

## Changes

- The custom pointer-drag bridge now mounts a lightweight GCM-owned preview as soon as a task drag crosses the movement threshold.
- A single task shows its title. A selected batch shows the exact task count so the user can confirm which selection is being dragged.
- The preview follows the pointer, is clamped inside the active Obsidian window, ignores pointer hit-testing, and is removed on drop, cancellation, or lost pointer capture.
- TPS List caches the exact selected task references for the duration of the drag, and TPS Table computes the selected count once, avoiding repeated selection scans on every pointer movement.
- The existing `tps-task-line-pointer-drop` payload and TPS Notebook Navigator mutation path are unchanged.

## Compatibility and migration

- Backward-compatible patch; minimum supported Obsidian remains 1.10.0.
- No settings, Base files, note data, commands, or public APIs change.
- Notebook Navigator's ordinary file dragging is unaffected.

## Validation

- The complete declared test suite passed, including 1,108 tests across the pretest and focused runners. New executable coverage verifies connected single-task and multi-task previews, pointer following, viewport clamping, and cleanup, while the existing List/Table cross-plugin payload tests remain green.
- The required separate TypeScript production build passed and deployed the exact candidate artifacts to the Obsidian Plugin Test Vault. Source and test-runtime artifacts match byte-for-byte.
- The deployed TPS List fixture loaded successfully with 16 task rows in the test vault. The preview lifecycle is additionally verified in an executable DOM harness; automated desktop coordinate dragging was unavailable in the multi-display test session.

## Known limitations

- Cross-plugin task drops remain desktop pointer interactions and require a concrete TPS Notebook Navigator property or tag target.
