# TPS Global Context Menu 1.34.11

TPS Global Context Menu 1.34.11 restores literal Source-mode behavior on mobile while retaining the persistent linked-context mounting and visible ordering controls from 1.34.9 and 1.34.10.

## Source-mode reliability

- Mobile Obsidian can report a Markdown source editor without persisting the desktop `source` boolean. GCM now falls back to the actual editor root in that case, distinguishing strict Source from Live Preview without treating Source as an enhanced editor.
- Strict Source shows the real Markdown content for headings, food-log entries, inline properties, hidden TPS metadata, and other task or line content.
- Linked context, inline-property chips, completed-task hiding, virtual Base overlays, linked-subitem controls, and other TPS editor substitutions remain absent in strict Source by design.
- Explicit Reading or Live Preview state still wins during a mode transition, preventing stale DOM from briefly misclassifying an enhanced view as Source.

## Linked context and settings carried forward

- Reading View linked context remains mounted outside Obsidian's virtualized preview sizer, so normal scrolling does not detach and rebuild the panel.
- Live Preview linked context remains outside CodeMirror content and preserves its stable DOM across routine refreshes.
- Empty heading excerpts remain omitted, and completed-task rendering retains the bounded, document-change-driven refresh behavior from 1.34.8.
- Sort controls are available under **Settings → TPS Global Context Menu → Menus & surfaces → Linked context → Linked context order**, with stable source-path ascending or descending ordering.

## Compatibility and known limitations

- Backward-compatible patch with no setting, default, public API, or note-data migration.
- Linked context is intentionally unavailable in strict Source mode because that mode is reserved for literal Markdown editing.
- Ordering remains limited to source-path ascending or descending; excerpts within a source keep physical document order.
- Minimum supported Obsidian remains 1.10.0.
