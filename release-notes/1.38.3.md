# TPS Global Context Menu 1.38.3

This backward-compatible patch makes the core Obsidian Tasks Base **New** button compatible with the native TPS record architecture.

## Fixes

- Obsidian creates a new Base row as a Markdown file beside the Base and materializes only positive property filters. For the POC Tasks Base, that meant a root `kind: task` file was immediately excluded by the required `_records/tasks/` path filter.
- In native-record mode, GCM now recognizes only a newly created, empty, unenveloped `kind: task` draft, adds its stable TPS identity and required timestamps, defaults blank status to `todo`, and moves that same file to `_records/tasks/<tpsId>.md`.
- Existing notes, notes with body content, non-task files, partial TPS envelopes, and Legacy-mode files are never adopted. The Base definition, settings schema, native record schema, and public API versions are unchanged.

Minimum Obsidian: 1.10.0. Tested in the isolated test vault and ready for the user's BRAT pull into the blank TishOS Native POC.
