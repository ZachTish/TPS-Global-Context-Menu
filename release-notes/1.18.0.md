# TPS Global Context Menu 1.18.0

Released: 2026-08-03

Minimum Obsidian version: 1.10.0

Entity Index API version: 3

## What changed

- Entity Index v3 block records can now expose an optional immutable `lineProperties` map for every canonical inline
  field authored on the exact task, bullet, or heading.
- Line-property values preserve authored order, repeated fields, blank values, and the casing of the first authored key.
  Note records never expose line properties, so consumers cannot mistake another line's inline fields for note metadata.
- Raw authored properties remain independent from indexed identity dimensions. Structural and configured Kind values stay
  in `dimensions`; arbitrary inline fields do not have to be registered before a consumer can sort or group by them.
- An edit that changes only an authored line property advances the Entity Index revision and invalidates its query cache,
  allowing consumers to refresh without a structural or Kind change.

## Compatibility and migration

- This is a backward-compatible additive capability. Existing Entity Index v3 consumers can ignore the optional field.
- No settings, note, or cache migration is required.
- Minimum supported Obsidian remains 1.10.0.
- TPS Notebook Navigator 5.4.0 consumes this capability for explicit Line-property grouping.

## Validation

- Focused Entity Index coverage verifies tasks, bullets, and headings; repeated and blank values; first-authored casing;
  protected Markdown and hidden carriers; deep immutability; note-record omission; revision changes; and asynchronous
  query-cache refresh after a line-property-only edit.
- All 49 focused Entity Index checks and the complete declared GCM test suite passed, followed by TypeScript and the
  mandatory separate production-mode build.
- The final build was deployed and reloaded only in **Obsidian Plugin Test Vault**. Runtime-owned `data.json` remained
  byte-identical and production was not accessed.

## Known limitations

- `lineProperties` is available only on addressable Markdown task, bullet, and heading block records. Note records use
  frontmatter through their existing indexed dimensions, and protected Markdown remains intentionally unindexed.
- Values are normalized as immutable strings. Consumers remain responsible for applying their own date, number, list, or
  other presentation semantics.
