# TPS Global Context Menu 1.24.3

Task tags edited from rendered task surfaces now remain real Markdown tags, and metadata-fragment clicks resolve the correct source task.

## Changes

- The task quick editor canonicalizes `tag`, `tags`, and tag-list property drafts to `#tag` values before writing the inline field.
- Existing tag prefixes are preserved without duplication, duplicate inputs stay deduplicated, and hierarchical tags remain supported.
- Task resolution now considers both the clicked fragment and the complete rendered task row. Clicking a tag or property value no longer narrows resolution to that fragment alone.

## Compatibility and migration

- Minimum Obsidian version: 1.10.0.
- No settings or note schema migration is required.
- Existing malformed plain tag values are left untouched until edited, avoiding an unsolicited vault-wide rewrite.

## Validation

- Focused regressions cover plain, prefixed, duplicate, and hierarchical tag drafts plus rendered-fragment task resolution.
- The complete declared test suite, TypeScript check, and separate production build were run against the final versioned artifact in the isolated Obsidian Plugin Test Vault.
- Production was not inspected or modified.

This release is tested in the isolated test vault and ready for the user's BRAT pull.
