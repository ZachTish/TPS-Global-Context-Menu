# TPS Global Context Menu 7.3.4

Backward-compatible fix; minimum Obsidian 1.10.0.

## Change

Whole-note deletion now honors the line/body-write retirement shipped in 5.0.0. It previously bypassed the shared mutation boundary, reading every Markdown body and potentially deleting historical inline links. Native mode now considers only stored parent/attachment properties. Matching properties still go through the protected atomic writer; historical bodies and completion fields remain authored. Legacy body cleanup retains its current-source parser and post-read frontmatter admission.

No new cache, watcher, setting, schema, migration, retry or repair system. Relationship cleanup remains best-effort: a new relationship not yet visible in core metadata may remain unresolved. Cache admission never authorizes overwriting newer source.

## Reminder rollout

The release retains 7.3.3's removal of the passive checklist completion rollback and 7.3.2's stale-write/rename fix. Downloading a plugin artifact is not the same as executing it. Receiving mobile devices must load the updated code; Obsidian documents that synced plugin changes can require a full app restart. This is not a new daily-refresh requirement. See [Obsidian Sync troubleshooting](https://obsidian.md/help/sync/troubleshoot).

Test-vault validated and ready for a production BRAT pull; not directly deployed to production.
