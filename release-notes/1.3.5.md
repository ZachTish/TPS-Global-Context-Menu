# TPS Global Context Menu 1.3.5

This patch routes every settings and runtime-state write through one merge-safe persistence coordinator.

## Changes

- Reloads current plugin data and applies only locally changed fields, preserving synchronized choices, archive state, and unknown fields.
- Retains rapid change/revert intent, allows queued newer values to supersede a failed write, and closes the drain-completion acknowledgement race.
- Startup migration and time-tracking updates no longer bypass the coordinator; settings text controls no longer depend on unload-unsafe timers.

## Compatibility and validation

- Minimum Obsidian: 1.10.0; desktop and mobile supported; no manual migration.
- Focused settings tests: 18/18 passed; TypeScript and diff checks passed.
- Full declared suite: 276/276 passed. A separate production-mode build deployed byte-identical artifacts to the isolated test vault.
- Obsidian 1.12.7 was reloaded with **Reload app without saving**; the GCM settings surface and TPS List test fixture rendered normally, and runtime-owned `data.json` remained unchanged.
- iOS software-keyboard geometry still requires confirmation on an iOS device; this release does not alter that UI contract.
