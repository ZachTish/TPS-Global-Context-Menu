# TPS Global Context Menu 1.3.5

This patch routes every settings and runtime-state write through one merge-safe persistence coordinator.

## Changes

- Reloads current plugin data and applies only locally changed fields, preserving synchronized choices, archive state, and unknown fields.
- Retains rapid change/revert intent, allows queued newer values to supersede a failed write, and closes the drain-completion acknowledgement race.
- Startup migration and time-tracking updates no longer bypass the coordinator; settings text controls no longer depend on unload-unsafe timers.
