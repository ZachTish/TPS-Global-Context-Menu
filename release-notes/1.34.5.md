# TPS Global Context Menu 1.34.5

TPS Global Context Menu 1.34.5 fixes the remaining top-placement Linked context scroll reset.

## Linked-context scroll stability

- Top placement never adds, moves, or replaces its top-of-note host while the Reading View or Live Preview scroller is more than 24 pixels from the beginning.
- The guard no longer depends on Obsidian removing the inline title from the DOM. A still-mounted offscreen title therefore cannot reopen the unsafe top-layout mutation path.
- A detached panel or newly rendered refresh is retained as deferred work and resumes when the same note returns to the top threshold.
- Bottom placement keeps the existing scroll-idle recovery behavior.

## Compatibility and known limitations

- Backward-compatible patch with no new setting, public API, note rewrite, or schema migration.
- A top-placed Linked context panel may remain temporarily detached or stale while the note is scrolled away from the beginning. This is intentional: it avoids changing top-of-document layout under Obsidian's virtualizer and refreshes when the user returns to the top.
- Minimum supported Obsidian remains 1.10.0.
