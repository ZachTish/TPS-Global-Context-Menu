# TPS Global Context Menu 1.11.9

This patch removes redundant rendered-link work from GCM's recurring title compatibility sweep without removing any released compatibility path.

## What changed

- Collects the same four rendered-root selectors once per Markdown leaf.
- Processes only candidates that do not have another candidate ancestor in the same invocation.
- Keeps disjoint rendered roots independent and in document order.
- Keeps title/icon reconciliation first and exactly once per valid Markdown leaf.
- Adds no persistent DOM cache, observer, retry, monkeypatch, or unsupported Obsidian API.

## Compatibility and migration

- This is a backward-compatible patch release.
- No command, setting, public API, note-data format, link target, or user workflow was removed or changed.
- The public Markdown postprocessor remains the normal render path.
- The 900 ms recurring sweep and all four host-DOM selectors remain for mobile/remount compatibility.
- Aliases, excluded menus/modals, split views, disjoint embeds, and per-view source-path routing are preserved.
- No settings or note-data migration is required.
- Minimum supported Obsidian version: 1.10.0.

## Measured effect

The compiled real-service benchmark used the exact released 1.11.8 source and the candidate against identical synthetic DOM trees for 100 iterations per case:

- Dense nested view: 503 DOM queries and 30,000 link-target resolutions became 2 queries and 10,000 resolutions. Median fell from 45.385 ms to 19.166 ms (57.8%); p95 fell from 56.991 ms to 23.301 ms (59.1%).
- Empty nested view: 503 DOM queries became 2. Median fell from 0.526 ms to 0.346 ms (34.1%); p95 fell from 1.395 ms to 1.372 ms.
- Fully disjoint view: both versions retained 501 DOM queries and 10,000 link-target resolutions. The measured 13.392 ms versus 12.913 ms medians are treated as effectively neutral; the structural work is unchanged.

These figures isolate the recurring rendered-link sweep rather than claiming a whole-application speedup.

## Known limitations

- The recurring sweep remains a compatibility layer over Obsidian's rendered DOM because mobile/remount behavior lacks an equivalent complete public lifecycle hook.
- This release intentionally retains every existing rendered-root selector. It removes only duplicate work when those candidates are nested.
- Existing transcluded-note remount source-path behavior and delayed title timers are unchanged and remain separate audit items.
