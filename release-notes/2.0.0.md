TPS Home has been removed from TPS Global Context Menu. Daily Notes open as ordinary Markdown, and workspace restoration no longer loads the Home dashboard or its panels.

- Removed the Home dashboard, component editing/actions, capture UI, Daily Note interception, and Home-specific CSS.
- Removed the five command IDs `open-home`, `home-quick-capture`, `capture-to-current-note`, `capture-to-home-note`, and `add-task-to-home-note`, plus `api.homeActions`.
- Renamed Workflows → Home & daily notes to **Daily notes**. Removed **Use TPS Home for Daily Notes** and **Home capture position**; all other settings and actions remain.
- Retired the eleven known Home settings. In the test vault, nine persisted Home keys were removed with no added keys or changes to other saved values.
- A one-time post-layout migration reopens saved Home tabs as their existing Markdown backing notes. Standalone or unavailable-note tabs become empty; failures/unavailable notes produce a notice. It does not register a Home view or create/delete notes.
- Preserved normal Daily Note navigation, task creation, inherited scheduling, time tracking, and standalone Bases. The shared line editor remains independent, including exact-source/fingerprint checks, atomic writes, task history and mobile input handling.

This is **2.0.0** because it intentionally removes a feature, commands, settings, and a public API capability. Minimum Obsidian remains **1.10.0**. Existing notes, captured text and Base files are retained. Old Home commands/hotkeys and external callers of its API must be removed or updated. Historical Home instructions no longer apply.
