# TPS Global Context Menu 1.3.0

TPS List and TPS Table can now group synthesized rows by the Markdown note that actually contains each task, bullet, heading, or line record.

## User-visible changes

- Choose `file.name` to group by containing filename or `file.path` to group by the unique vault-relative containing-note path.
- Source-note aliases also include `file.basename`, `file.link`, `file.folder`, `file.ext`/`file.extension`, `task.path`, `task.file.path`, `line.path`, and `heading.path`.
- TPS List source-note grouping works in standalone, task-only, getter-backed, and Markdown-embedded Base views.
- TPS Table renders a labeled row-group header for every containing note. The headers are read-only and non-selectable, global totals remain global, and Shift-selection follows the grouped visual order.

## Reliability and compatibility

- Native Base groups and synthesized TPS List task lanes now use the same case-insensitive lane identity while preserving the source path's display casing. Mixed-case paths can no longer produce an apparently empty task list.
- Source-note groups are intentionally read-only. Dragging a TPS List row cannot write a `file.*` or path alias into task metadata.
- `file.name` intentionally merges identical filenames from different folders; use `file.path` when those notes must remain distinct.
- Minimum supported Obsidian version: 1.10.0.
- No settings or data migration is required.

- A standalone and Markdown-embedded TPS Table each rendered 14 lines under three distinct `file.path` source-note row headers.

- The final source artifacts are byte-identical to the isolated test-vault runtime.

## Known limitations

- Filename grouping cannot distinguish same-named notes by design; choose `file.path` for unique groups.
- Source-note group lanes cannot be used as drag-and-drop mutation targets because their values are derived from the row's containing file.
- The grouping behavior is platform-neutral and regression-covered, but the UI verification was performed in the isolated macOS test app rather than on an iOS device.
