# TPS Global Context Menu 1.6.0

This minor release replaces GCM's deep settings accordion tree with a compact routed settings hub.

## User-visible changes

- Adds five top-level destinations: Rules & fields, Menus & surfaces, Workflows, Appearance, and Advanced.
- Rules & fields uses direct selectors for Frontmatter rules, Custom fields, and View mode, with a compact second selector for Sort buckets, Tag rules, and Icon + color.
- Workflows exposes Home & daily notes, Tasks, Child notes, Recurrence, and Time tracking directly instead of nesting them under multiple accordion levels.
- Limits disclosures to advanced safeguards, repeated custom-field editors, and the compact Base reference.
- Adds mobile-safe horizontal route strips, stacked view-mode rows, namespaced settings CSS, and keyboard-focus restoration.

## Compatibility and migration

- Minimum supported Obsidian version: 1.10.0. Desktop and mobile are supported.
- Existing setting keys, defaults, actions, and normalized payloads are unchanged; no settings migration is required.
- Repeated custom fields remain individual disclosures by design, and narrow screens scroll the route strips horizontally rather than showing every destination vertically.
- GitHub Actions standalone builds remain unavailable because this contained layout imports the adjacent shared deployment helper.
