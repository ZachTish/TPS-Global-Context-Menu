# TPS Global Context Menu 7.3.5

Backward-compatible performance fix. Whole-note Calendar shortcuts no longer calculate a vault-wide event count on mount and every eleven seconds. The shortcut shows Calendar or the running elapsed timer; clicking it still queries current events. Native popovers no longer inspect retired inline checkbox records. Legacy-mode counts and inline display are unchanged. No note rewrite, settings migration, new cache or watcher.
