# TPS Global Context Menu 1.38.1

This backward-compatible patch hardens the native-record identity contract introduced in 1.38.0.

## Fixes

- Native task, calendar, food, activity, workout, and asset records are restored to their stable ID-based filenames if a user or plugin renames them.
- Canonical restoration never overwrites an occupied path; conflicts fail closed and remain diagnosable.
- Legacy mode, existing settings, record schemas, and public API versions are unchanged.

Minimum Obsidian: 1.10.0. Tested in the isolated test vault and the blank TishOS Native POC, and ready for the user's BRAT pull.
