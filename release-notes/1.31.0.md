# TPS Global Context Menu 1.31.0

TPS Global Context Menu `1.31.0` makes task-to-bullet conversion a first-class Status choice and keeps task context menus compact when task titles or property values are long.

## Task Status conversion

- **Bullet — No status** now appears after the configured checkbox mappings in the normal task context menu, the standalone checkbox status picker, the task quick editor, and the selected-task Status submenu.
- Conversion reuses GCM's existing exact-line task mutation. It clears checkbox-owned status/completion fields, removes only the checkbox syntax, preserves unrelated task text and inline metadata, and leaves nested child lines untouched.
- The former task is recorded as a confirmed terminal item-history event. Stale, ambiguous, changed-mapping, and unconfirmed writes still abort without converting another line.

## Compact task menus

- Root task menus and their GCM-owned nested submenus display at most 25 Unicode characters including the ellipsis; DOM menus also retain a `25ch` CSS ceiling.
- When Obsidian exposes a DOM menu item, GCM preserves the complete title, source-note name, property value, tag, or other label as its tooltip and accessibility label.

## Compatibility and data effects

- This is a backward-compatible minor release. It adds no setting or public API and performs no bulk note migration.
- A task changes only when the user explicitly chooses **Bullet — No status**. Existing task checkbox mappings and custom checkbox values are unchanged.
- Minimum supported Obsidian version remains `1.10.0`.

## Known limitations

- The 25-character limit applies to GCM task menus and their GCM-created submenus, not every Obsidian or third-party context menu.
- Converting a task to a bullet is intentionally a terminal task-history transition; converting that bullet back into a task is a separate user action.
