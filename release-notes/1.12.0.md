# TPS Global Context Menu 1.12.0

This backward-compatible minor release adds the strict, plugin-owned Base-line editing handoff required by the TishOS companion app. It was validated only in the isolated Obsidian Plugin Test Vault and was not installed in production.

## What changed

- GCM registers the public Obsidian protocol action `tps-gcm-edit-base-line`.
- A valid request opens the exact existing `Base.path#View name` through Obsidian's public workspace link API, then opens GCM's existing **Edit line** modal for the resolved Markdown line.
- Opening the URI, Base, or modal performs no vault mutation. The line editor retains its explicit Save/Cancel UI and existing guarded atomic replacement.
- The handler accepts exactly these version-1 query keys: `v`, `vault`, `base`, `view`, `source`, `line`, `fingerprint`, and `nonce`. There is no arbitrary command or generic URL-action input.
- Requests are bound to the current exact vault name, an existing canonical `.base` path, exactly one parsed view with the requested exact name, and an existing canonical Markdown source path. Extension matching is case-insensitive, while the resolved vault path itself must match exactly.
- The vault name is capped at 160 characters. Base definitions larger than 512 KiB and Markdown sources larger than 2 MiB in UTF-8 are refused before parsing or hashing.
- The one-based line is only a bounded hint. GCM computes lowercase SHA-256 over each current NFC-normalized physical line after CRLF normalization and proceeds only when one—and only one—line matches the supplied hash. A leading UTF-8 BOM is ignored only for physical line one.
- GCM rechecks the supplied hash once more while opening the modal and after the user selects **Save changes**. The modal's exact snapshot check remains the final in-process guard, so a race after digest validation still cannot overwrite a changed note.
- Lowercase UUID nonces are deduplicated while active and for five minutes after completion, with retained replay state capped at 256 entries. Structured route logs omit the vault name, file paths, view name, line number, fingerprint, nonce, note content, and raw thrown errors; the same redaction applies to externally routed editor recheck failures.

## Compatibility and migration

- This is an additive protocol and does not replace any existing GCM row, menu, task editor, capture, or note-opening behavior.
- No settings or note-data migration is required.
- Minimum supported Obsidian version: 1.10.0.
- The paired TishOS build must emit action `tps-gcm-edit-base-line`, protocol `v=1`, a lowercase UUID nonce, and the same NFC/CRLF/lowercase-SHA-256 fingerprint definition.
- Base paths and view names containing fragment/control delimiters are refused; ordinary percent-decoded `&` and `?` characters in a view name remain valid. Missing, renamed, stale, or ambiguous targets fail closed and ask the user to refresh the widget.

## Validation

- `node --test scripts/test-base-line-edit-protocol.mjs`: 12/12 focused checks passed, including Obsidian's implicit `action` field boundary, first-line BOM handling, byte ceilings, uppercase extensions, duplicate-view refusal, bounded nonce memory, and redacted error logging.
- The complete declared `TPS_NO_DEPLOY=1 npm test` suite passed from the isolated release worktree. The final versioned run included the complete pretest gate, every repository test command, TypeScript, and a production build with runtime deployment disabled.
- The mandatory separate versioned `TPS_NO_DEPLOY=1 npm run build` passed. The resulting four release artifacts were then atomically copied to the test-vault runtime; source and runtime SHA-256 hashes match exactly, and the runtime-owned `data.json` hash remained `955b97d05a4a473a1ee98696cde354f8fbbcf4f566ccb4c5ffcdb74ae8244eeb` before and after deployment.
- Obsidian 1.12.7 was reloaded with **Reload app without saving** in the verified `Obsidian Plugin Test Vault`. A real external version-1 URI opened `Inbox/TishOS List Table QA/Phone Table QA.base#Phone Table QA` first and then displayed GCM's guarded **Edit line** modal for `Inbox/TishOS List Table QA/Table Rows.md` line 1. The modal was canceled; no Save action or test-note mutation occurred.
- Production was not accessed or changed.
