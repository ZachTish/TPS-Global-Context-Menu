# TPS Global Context Menu 1.10.1

## What changed

- Accepted-Kind relationship fields configured for the context menu now use the same constrained entity picker everywhere the selected record can be edited: whole notes, task lines, TPS List bullets and headings, and non-task TPS Table records.
- Each relationship picker shows only notes and line-backed entities registered with the property's accepted Kind. The picker remains generic: Projects can be restricted to project entities, Contexts to context entities, and other configured relationships to their own Kind without hardcoded entity names.
- Scalar relationships write one canonical Obsidian link. List relationships add deduplicated canonical links and support removing one selected relationship or clearing the field.
- Context-menu visibility now evaluates the selected line's semantic tags and inline-property state correctly, including fields that are present but blank. Disabled, hidden, or context-menu-disabled fields remain excluded.
- Task context-menu relationships are independent of the `@@` inline-insertion setting. A relationship configured for the right-click menu remains available even when `allowInlineSet` is disabled.
- TPS List heading rows now bypass the document-level note interceptor, so right-clicking a heading opens the heading's own relationship menu rather than the containing note's menu.
- Bullet, heading, task, and table-record mutations resolve the current source line immediately before writing. These line-local edits preserve surrounding inline properties and block IDs and do not redirect relationship values into the containing note's frontmatter.

## Compatibility and migration

- This is a backward-compatible patch release.
- No settings or stored-value migration is required. Existing Kind identities, accepted-Kind constraints, scalar links, and list links remain valid.
- Minimum supported Obsidian version: 1.10.0.

## Known limitations

- Accepted-Kind pickers intentionally provide no free-text or implicit note-creation escape hatch.
- Right-click relationship parity applies to properties configured with an accepted Kind. Other custom-property editor behavior is unchanged in this patch.
