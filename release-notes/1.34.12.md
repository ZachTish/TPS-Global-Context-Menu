# TPS Global Context Menu 1.34.12

TPS Global Context Menu 1.34.12 fixes a cross-plugin CSS collision that could visibly cut off the bottom of a TPS Notebook Navigator list in an existing popout.

## Navigator popout recovery

- GCM Frontmatter Rules settings no longer reuse TPS Notebook Navigator's `tps-nn-*` DOM and CSS namespace. Their rule editor, list, condition, overview, and Base-query surfaces now use GCM-owned names.
- The copied settings stylesheet now ships in GCM's normal `styles.css`, scoped to its settings surfaces, instead of being permanently inserted into `document.head`.
- GCM removes the legacy injected stylesheet on load, unload, and when a new popout opens. This recovers an already-open Navigator window without restarting Obsidian.
- The underlying leaked rule capped `.tps-nn-list-pane` at `min(72vh, 760px)`. The correction removes that foreign cap at its source; it does not add a Navigator override or padding workaround.

## Compatibility

- Backward-compatible patch with no settings, defaults, public APIs, or note-data migration.
- Minimum supported Obsidian remains 1.10.0.
