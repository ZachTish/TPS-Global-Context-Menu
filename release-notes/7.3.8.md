# TPS Global Context Menu 7.3.8

Test-vault-validated BRAT handoff. Publication is separate from installation in
the user's production vault.

Backward-compatible performance correction for native-record inspection.
The prepared readable profiles now retain the same objects used by the
identity-evidence and current-kind passes. Their former normalized clones
caused the existing operation-local inspector to classify equivalent profiles
again. Normalization remains in profile validation and alias deduplication;
public profile getters and inspection results still return detached copies.

All evidence, ambiguity, duplicate-key, classification and timestamp checks
remain active. Scalar and list classifications stay distinct. Inspection still
uses current frontmatter and a value-based settings signature, including
in-place nested mapping edits and migration-mode changes. Results are not
reused across notes, inspections, edits or mutation boundaries. No persistent
cache, index, watcher, timer, heuristic metadata skip, automatic repair or note
write is added. Navigator invalidation, sorting and public APIs are unchanged.

This warrants a patch version: supported behavior, settings, stored schema and
minimum Obsidian 1.10.0 remain unchanged. No migration is required.

## Focused validation

- Strict tests first failed against the published 7.3.7 source: 10,000 canonical
  title inspections made 40,000 classifier calls versus the required 30,000;
  the twelve-kind/list-mapping fixture with one scalar alias per kind made
  490,000 calls versus the required 250,000.
- Both fixtures now meet those exact lower counts on the initial and repeated
  10,000-note passes, preserving every returned ID, kind and title and the
  source metadata. The classifier's raw-to-envelope copies fall from 20,000
  to exactly 10,000 per pass in each fixture. This counter does not count
  every object spread or match-set merge copy inside inspection.
- Four new tests cover those repeated batches plus normalized aliases,
  reordered profile fields, case-insensitive reads, custom classifications,
  detached public profiles, live title/status changes, scalar/list distinctions,
  conflicting classification/identity evidence and nested setting changes
  between inspections. Existing exact-count tests were updated to the lower
  exact expected work; no bound was loosened and no test was skipped.
- `node --test scripts/test-native-record-service.mjs`: 142 passed, zero
  failures or skips. Independent targeted review ran 11 relevant tests,
  including both 10,000-note fixtures, with zero failures or skips.
- The preceding in-memory audit compared 3,630 baseline/proposed inspection
  outputs and source objects across current and migration profiles. A separate
  actual Navigator title-sort probe retained the identical complete sorted
  10,000-file order. These are synthetic source-method checks, not full React
  rendering, installed foreground input-to-paint or physical-device evidence.

## Final validation

- Final versioned `TPS_NO_DEPLOY=1 npm test`: 1,588 passed, zero failures,
  cancellations or skips, including TypeScript and the production build.
- Explicit supplemental `TPS_NO_DEPLOY=1 npm run prepretest`: 214 passed,
  zero failures, cancellations or skips. The first concurrent run had one
  pre-existing timer-sensitive Daily Note settlement test report timeout before
  configuration change; the identical full sequential rerun passed. No test
  assertion or timeout was weakened.
- A separate production-mode build deployed only changed `main.js` and
  `manifest.json` to the Test vault. Named-plugin reload and refreshed manifest
  confirmed loaded 7.3.8. All four installed artifact hashes match source;
  `data.json` remains byte-identical.
- The same guarded installed probe ran actual loaded 7.3.7 and 7.3.8 inspection
  over three batches of 10,000 synthetic records. All 30,000 IDs, kinds and
  titles were correct in each version; complete output, fixture, configuration
  and settings hashes match. Ordinary/missing/conflicting-identity and unknown
  kind cases preserve identical outcomes and input bytes.
- Current Test settings use the canonical property profile, so installed
  list/tag mapping coverage was explicitly absent. Those configurations remain
  covered by the source regressions. The prepared readable profile now shares
  its existing evidence/current object; reference overlap is supporting evidence,
  not a classifier-call or allocation counter.
- Warm synchronous batch times were 213.5/183.2/175.3 ms before and
  172.1/166.0/163.1 ms after. Validation/hashing occurred outside timing. The
  window was hidden and unfocused; inputs were synthetic and no vault I/O or
  note/settings writes were performed. These are elapsed method timings,
  including GC, not foreground input-to-paint, cold startup or device speed.
- Health 4.2.3, Controller 3.1.4 and Navigator 8.2.1 remained enabled. The
  separate daily-display navigation diagnostic confirmed real Live Preview
  widgets and retained roots, but found a Navigator drawing-metadata sizing
  pass that this patch does not change. Do not attribute that pass to native
  record inspection.

The synthetic measurements identify avoidable synchronous inspection work;
they do not establish a multi-second mobile/Windows root cause or eliminate
all note-opening, swiping and tab-switching delays. Physical-device acceptance
remains separate. Production installation remains the user's BRAT pull.
