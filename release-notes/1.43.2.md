# TPS Global Context Menu 1.43.2

This backward-compatible patch makes GCM the deterministic Daily Note identity and reconciliation owner for TPS plugins, including flat vaults where many unrelated records begin with a date.

- Calendar, food, workout, task, and other date-title records cannot be mistaken for a Daily Note.
- A unique strict legacy Daily Note can move atomically to the current canonical path; ambiguity, conflicting metadata, collisions, and startup uncertainty fail closed.
- Daily Notes API v4 adds optional expected-path enforcement for race-free cross-plugin creation while preserving v2/v3 and one-argument compatibility.
- Core, Periodic, persisted startup, naming, and creation paths share one ready configuration snapshot and one cached candidate index.
- Templater is awaited only for newly owned work. Mature notes stay byte-stable, and failed owned output is retained non-destructively with durable or same-session evidence.

Minimum Obsidian: 1.10.0. No settings or note migration is required.
