# TPS Global Context Menu 1.1.0

TPS List and TPS Table row menus now expose tag management as a built-in Base action, including when **Show custom properties in context menu** is disabled.

## User-visible changes

- TPS List note rows can add and remove note frontmatter tags.
- TPS List task rows and task-shaped TPS Table rows can add and remove Markdown `#tags` on the exact task line.
- TPS List bullet rows expose a clearly scoped **Line tags** action.
- Generic TPS Table records can add and remove tags through their inline `[tags:: #tag, ...]` field, so existing tag columns and filters continue to work.
- The built-in action replaces, rather than duplicates, a configured Tags property on the same menu. TPS Table reserves only canonical `tags`; a distinct singular `tag` column remains normally editable.

## Compatibility and migration

- Minimum supported Obsidian version: 1.10.0.
- No settings or data migration is required.
- Existing tags and configured property definitions are preserved.

## Known limitation

- TPS Health food rows continue to use the TPS Health domain-specific context menu and do not use this GCM-owned Base-row action.
