# TPS Global Context Menu 1.26.0

TPS Global Context Menu `1.26.0` makes the Calendar, Tasks, and Mentions controls individually configurable and places their settings where users expect to find note-surface controls.

## Changes

- Add independent **Show Calendar button**, **Show Tasks button**, and **Show Mentions button** toggles under **Menus & surfaces → Note navigation**.
- Move the existing note-navigation master and placement controls out of **Workflows → Child notes** and into the same flat note-navigation section without changing their persisted keys.
- Apply each choice consistently below the title and in the bottom toolbar, with immediate cache invalidation when a setting changes.
- Keep the scheduled Daily Note shortcut independent from the Calendar popover toggle.
- Remove empty navigation rows, including rows whose only registered external actions resolve hidden or fail asynchronously, while preserving a shared host that still contains Linked Context.

## Compatibility and migration

- The three new visibility settings default to enabled, so existing installations keep their current buttons until the user turns one off.
- The existing `enableTopParentNav` master and `topParentNavPlacement` setting remain authoritative and require no migration.
- No public API, command, or note schema changed.
- Minimum supported Obsidian version remains `1.10.0`.
