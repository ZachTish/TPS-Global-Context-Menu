# TPS Global Context Menu 1.11.7

This patch removes GCM's application-wide frontmatter monkeypatch while preserving every GCM-owned write through the explicit mutation service.

## What changed

- All 42 GCM-owned Markdown mutation sites now call `FrontmatterMutationService` explicitly.
- GCM no longer assigns, marks, stores, or restores `app.fileManager.processFrontMatter`.
- Advanced Canvas resolves the current third-party writer at call time and preserves its function identity and receiver.
- Unrelated plugins regain Obsidian's documented native writer return, error, option, and lifecycle behavior.
- The supported `plugin.api.frontmatter` and legacy `processFrontmatter` aliases remain available to cooperating TPS plugins.

## Compatibility and migration

- This is a backward-compatible patch release.
- No command, setting, public API, Canvas property workflow, note-data format, or GCM-owned feature was removed.
- No settings or note-data migration is required.
- Minimum supported Obsidian version: 1.10.0.

## Validation

- The exact 1.11.6 source had 42 GCM-owned direct `processFrontMatter` sites and globally replaced the host method at load.
- The final TypeScript-AST gate permits only one read-only writer lookup in the Advanced Canvas bridge and finds zero host calls, assignments, deletes, or updates elsewhere.
- A Proxy-backed Canvas harness proves success, no-op, and rejected writes preserve exact writer identity and receiver with zero assignment/delete traps.
- Before the change, 533 declared checks passed. The candidate passes all 536 declared checks, TypeScript, the suite's production-mode build, and the mandatory separate final build.
- In Obsidian 1.12.7, the released 1.11.6 runtime's native writer carried the GCM marker and returned `true`; the candidate retained an unmarked stable native identity, returned native `undefined`, and persisted the same requested status/tags. A public GCM API write still returned `true` and used the normalized owned route.
- A 200,000-call dispatch-only benchmark reduced median time from 22.097 ms through the released wrapper to 10.316 ms by removing every redundant wrapper dispatch.
- Both synthetic native-write notes were moved directly to `_archive`. Runtime-owned `data.json` remained byte-identical and production was not accessed.

## Known limitations

- The test vault does not have Advanced Canvas installed. Its integration is covered by the Proxy-backed current-writer contract and existing Canvas bridge regressions rather than a live Advanced Canvas UI mutation.
- The separate Advanced Canvas JSON persistence compatibility fallback is unchanged. Removing or replacing it requires its own schema/concurrency audit and live Advanced Canvas validation.
- External plugins that intentionally want GCM normalization, activity entries, explicit events, or immediate entity-index updates must use the supported public GCM frontmatter API; direct Obsidian calls now remain native.
