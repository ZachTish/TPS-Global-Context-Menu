# TPS Global Context Menu 1.34.0

TPS Global Context Menu 1.34.0 adds an explicit, scoped import of TPS Health property definitions while keeping Health as the sole owner of its schema.

## Health property import

- **Rules & fields → Custom fields → Import TPS Health properties** reads the live Health 0.10.0 property catalog only when the user presses **Import / refresh**.
- Reusable-food fields inherit Health's current tag-only, folder-only, frontmatter-only, or combined scope, so they appear only on notes Health currently recognizes as foods.
- Nutrition rollups require both Health's `healthUpdatedAt` marker and the individual populated rollup property, limiting them to Daily Notes where Health actually wrote that rollup.
- Importing is idempotent. Matching Health keys are refreshed instead of duplicated, retired imported entries are removed, and unrelated custom fields and notes are left unchanged.
- If Health is disabled or too old to expose `getPropertyCatalog()`, the import button is disabled with an explanatory message.

## Compatibility and known limitations

- Backward-compatible opt-in minor release with no automatic setting or note migration.
- TPS Health 0.10.0 or later is required. Changes to Health identification settings, configured tag/folder, or food-rollup goals require another explicit import.
- Minimum supported Obsidian remains 1.10.0.
