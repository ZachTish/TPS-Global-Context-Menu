# TPS Global Context Menu 1.22.1

## What changed

- Restores linked-context task checkboxes to Obsidian's normal checkbox dimensions on desktop and mobile.
- Keeps the canonical task context menu available through desktop right-click and mobile long-press.
- Preserves the compact linked-context card spacing, wrapping, and scroll-safe touch behavior from 1.22.0.

## Compatibility and validation

- No settings, note data, or frontmatter migration is required.
- Minimum supported Obsidian version remains 1.10.0.
- Focused linked-context interaction and TypeScript checks passed.
- The full declared suite and final production build were run against the isolated test-vault runtime.
- Live UI automation was skipped because the active Obsidian window was the production vault, which was not authorized for access.

This public build is ready for a user-controlled BRAT pull.
