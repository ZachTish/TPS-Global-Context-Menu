# TPS Global Context Menu 1.49.1

This patch repairs the Daily Note provider handshake during Obsidian cold startup.

- When a Daily Note API consumer observes that MetadataCache identity is not ready, GCM now remembers that blocked observation and republishes its existing API once identity becomes readable.
- The initial MetadataCache `resolved` event therefore gives TPS Notebook Navigator and other consumers a deterministic retry signal instead of leaving an empty Daily Note calendar until a reload or unrelated refresh.
- Read-only API lookup checks the exact configured Core Daily Notes path first, so a real canonical note remains openable during startup even when an unrelated legacy candidate is ambiguous or malformed. Cached authoritative non-Daily identity and unresolved non-empty files are rejected, while creation, migration, and reconciliation remain strictly fail closed.
- The public all-files `resolved` event is authoritative even when Obsidian legitimately keeps `getFileCache()` null for a zero-byte Markdown file. Empty Daily Notes and unrelated empty notes no longer hold all Daily Note identity reads and reconciliation in a permanently blocked state.
- Metadata-event floods now share one serialized background refresh with a trailing replay. Stable malformed frontmatter is quarantined from observational lookup but continues to block every Daily Note mutation until it changes or is removed.
- Core's exact startup placeholder now recovers a saved Daily Notes folder and filename format even when the user intentionally configured no template.
- Repeated blocked reads are coalesced into one readiness event, and duplicate `resolved` events stay silent until another blocked state is actually observed.
- No settings, note properties, Daily Note files, paths, or public API shape change. Minimum supported Obsidian remains 1.10.0.

Validation passed 89 focused Daily Note tests and the complete declared suite with 1,236/1,236 tests, followed by the mandatory separate production build. After a cold reload of Obsidian 1.13.7 in the isolated test vault, TPS Notebook Navigator immediately opened the configured zero-byte `2026-08-25` and populated `2026-08-26` Daily Notes without a creation prompt. The folder retained all 11 files and both note hashes were unchanged. Production was not accessed.

This release was tested in the isolated Obsidian Plugin Test Vault and is ready for the user's BRAT pull.
