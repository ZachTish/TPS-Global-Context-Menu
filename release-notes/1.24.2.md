# TPS Global Context Menu 1.24.2

Notebook Navigator icon and color rules now respond on the device where a note is opened.

## Changes

- Note-open visual rules run on controller-role, user-role, desktop, and mobile devices when the existing rule and auto-apply settings are enabled.
- The note-open coalescing delay is reduced from two seconds to 75 ms.
- Local note-open writes are limited to the configured icon and color fields.
- Smart-sort and hide-tag mutations remain controller-owned through startup and metadata-change automation.
- Existing exclusions, recent-edit protection, navigation-input protection, rule precedence, and clear-on-no-match behavior remain in effect.

## Compatibility and migration

- Minimum Obsidian version: 1.10.0.
- No settings or note schema changes are required.
- TPS Controller requires no companion change because the prior ownership gate was inside GCM.

## Validation

- Focused rule-engine regressions verify local note-open eligibility, the 75 ms delay, visual-only mutation scope, and retained controller ownership for sort/hide automation.
- The complete declared test suite, TypeScript check, and separate production build were run against the final versioned artifact in the isolated Obsidian Plugin Test Vault.
- Production was not inspected or modified.

This release is tested in the isolated test vault and ready for the user's BRAT pull.
