# TPS Global Context Menu 1.7.2

## What changed

- Bare `tag` and `tags` filters now resolve against task-row tags in TPS List and TPS Table, just like the explicit `task.tag` and `task.tags` aliases. Clean Base expressions such as `tags.contains(waiting)` no longer need a `task.` prefix.
- Task tags are collected from raw Markdown `#tags`, `[tag:: …]`, and `[tags:: …]` fields. Matching is exact, accepts an optional leading `#`, and preserves Unicode and nested tag paths, so `waiting` does not accidentally match `waiting-room`.
- `file.tags` remains a separate namespace for tags on the containing note.
- TPS Table uses the actual Markdown checkbox structure to decide whether a row is a task, preventing an editable inline `kind` field from spoofing task-only filter behavior.

## Compatibility and migration

- This is a backward-compatible patch release.
- No settings migration or note-data migration is required.
- Minimum supported Obsidian version: 1.10.0.

## Validation

- TypeScript validation passed.

- The example Base, its three source fixture notes, and runtime-owned plugin settings remained byte-identical through the reload.
- Production was not accessed or changed. This release is ready for a BRAT pull.
