# TPS Global Context Menu 8.0.0

Removes automatic editor mode rules, per-note enforcement, their command and the
stale-mobile editor-state replay. Core Obsidian controls and GCM's manual mode
actions remain; the manual-actions toggle is in Menus & surfaces. Existing notes
are not migrated or rewritten. Four retired automatic-mode settings are removed
on load/save. Major version: intentional removal of configured behavior.

Time tracking now installs its timers and listeners only while enabled, cleans
up on disable/unload, and rejects late results after activation changes. Enabled
sessions, status display and explicit timer actions retain their existing data
and APIs. No new repair, retry, cache or background scheduler is added.

The sole existing recurrence recovery worker accepts optional changed paths;
empty scopes and unchanged calendar runs avoid work. Full startup/manual checks
remain, and queued scopes/full requests are coalesced without dropping arrivals.
Scoped calendar sync no longer catches up unrelated completed notes as a side
effect; existing startup/completion actions own that catch-up. Failed work drains
independent pending requests once and rejects joined callers with the first
error, without automatic retry or a new scheduler framework. Existing creation
`handled:false` failure responses are unchanged.

Current bytes from the existing protection read own recurrence/completion and
successor markers, preventing a stale queued pass from creating another undated
tracker successor. The unchanged parser moves to a pure utility with its old
export retained; extraction adds no read. Fourteen regressions cover scoped and
full operation counts, actual creation, stale metadata, overlap and failures.

Expected installed settings delta: only `enableViewModeSwitching`,
`viewModeFrontmatterKey`, `viewModeIgnoredFolders`, and `viewModeRules` disappear
through the existing loader. Manual mode and time-tracking preferences remain.
No note or recurrence session data is migrated.

Initial focused validation: 174 tests pass, including actual service scans,
1,000-file disabled bursts, 100 registered callback bursts, enabled-session
restoration and lifecycle races. The full versioned `npm test` passes 1,680 checks
and the separate supplemental `npm run prepretest` passes 290 checks, with no
failures, cancellations or skips. TypeScript and the separate production-mode
preflight build pass with deployment suppressed by `TPS_NO_DEPLOY=1`. Candidate
artifacts were deployed only to Obsidian Plugin Test Vault; an affected-plugin
reload verified loaded version 8.0.0 and its ready API.

Installed foreground QA with all eight active TPS consumers enabled preserves
the synthetic fixture body and requested core Live Preview state. First and
repeated open pairs have zero automatic-mode decisions, mutations, stale checks
or replays, against one decision, mutation and stale check in the baseline pair.
Two core/other-consumer raw reads remain per pair; inventories and note writes
are zero. Native Reading → Editing controls work in both directions. Rules &
fields shows only Navigator rules and Custom fields; Menus & surfaces shows the
manual mode controls preference and Reading/Live Preview/Source description.

One hundred repetitions of the installed disabled timer's `getActiveTimers()` and
`getRuntimeStatus()` control perform zero inventories, reads or writes; lifecycle/cache
owners and the dock are absent. Installed GCM/Controller recurrence controls use
synthetic vault/metadata/frontmatter/journal/daily-exclusion boundaries: unchanged
sync dispatches zero work, changed ordinary notes dispatch once without source
reads or inventory, full startup retains one inventory, and overlapping requests
with stale metadata produce one successor for both daily and undated tracker
rules. No real notes are mutated and no network calls occur.

Saved-state comparison confirms installed GCM settings equal their baseline
after deleting exactly the four retired mode keys, all of which are absent.
Other consumer data hashes and the enabled community-plugin list are unchanged;
no note's view-mode property was edited. The final normal production build passed with byte-identical artifacts and
reported the test runtime unchanged. Public release publication is the remaining handoff step. Minimum Obsidian: 1.10.0.
Production has not been changed.
Physical iPhone timing, real import performance and input-to-paint latency are
not established by this QA.
