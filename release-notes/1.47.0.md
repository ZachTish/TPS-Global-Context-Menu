# TPS Global Context Menu 1.47.0

GCM now exposes its responsive local note editor as a guarded version-1 workspace capability for trusted TPS workflows such as Calendar's new post-create preview.

- `ui.openEditableNotePreview(...)` accepts one Markdown path, a connected anchor in the caller's window, the source plugin ID, and an optional initial-focus preference. GCM validates the request and opens its own card directly; it does not depend on Hover Editor or probe another plugin's registry.
- The rendered body is read-only. Editing uses an authoritative raw-Markdown textarea, so links, wikilinks, tasks, callouts, embeds, formatting, frontmatter, BOM, and uniform LF/CRLF line endings are never regenerated from rendered HTML. Mixed or legacy CR-only line endings are declined rather than normalized.
- Body saves use `Vault.process` against the exact body revision. An external conflict or save failure keeps the card open with the unsaved text instead of overwriting newer content or silently dismissing the editor.
- X, Escape, and outside dismissal flush pending edits before closing. Replacement, unload, and delayed-save paths are session-guarded so an older preview cannot update or close a newer one.
- The card uses the caller's document and window, supports pop-outs, and becomes a keyboard-aware bottom sheet on mobile. Desktop callers may focus the source editor immediately; mobile callers can open it with a tap.

This is an additive public UI capability with no setting, note, record, schema, or command migration. Existing Base-link preview behavior remains compatible. Minimum supported Obsidian remains 1.10.0.
