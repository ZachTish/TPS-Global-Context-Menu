# TPS Global Context Menu 1.44.0

This backward-compatible feature makes the Daily Note navigation timeline match compact workflows without removing the established full-week default.

- **Appearance → Daily Note Navigation → Visible day buttons** accepts one through seven days.
- Counts below seven form one contiguous range around the active Daily Note; even counts place the extra date before the active day.
- Seven remains the default and preserves the historical ISO Monday-Sunday strip.
- The current strip refreshes immediately after a setting change. Previous, Today, and Next navigation are unchanged.

Minimum Obsidian: 1.10.0. Existing settings and notes require no migration.
