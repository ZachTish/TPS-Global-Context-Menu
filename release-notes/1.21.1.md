# TPS Global Context Menu 1.21.1

## Linked-context presentation and tasks

- Removes the outer linked-context box so each source card supplies its own hover/focus treatment.
- Heading excerpts omit the linked heading and show only its nested body while retaining the heading as the source-open location.
- Single-line excerpts wrap naturally with compact list and task spacing.
- Task checkboxes are interactive in line, heading-body, and whole-note excerpts. They use GCM's canonical guarded completion API and configured workflow mappings without opening the source. Other linked content stays read-only.

## Compatibility and validation

- Backward-compatible patch with no settings or note-data migration.
- Minimum supported Obsidian version: 1.10.0.
- Focused linked-context regressions, TypeScript, the complete declared suite, mandatory separate production build, and test-vault deployment passed.
- Tested in the isolated test vault and ready for a BRAT pull. Production was not accessed.
