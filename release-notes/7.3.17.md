# TPS Global Context Menu 7.3.17

Typing an ordinary Markdown heading no longer searches every note for possible
links. The unsolicited heading suggestion feature is retired at the user's
request: its service, startup registration, editor/keyboard listeners and popover
styles are removed entirely. Obsidian's native `[[` link completion remains.
Independent heading folding, native preview, title rendering and body selection
retain their existing owners. No replacement, feature toggle, watcher, cache,
repair path, settings migration or note mutation is introduced.

This is a patch release removing a demonstrated editing performance defect,
with unchanged public APIs, stored settings and minimum Obsidian 1.10.0.

## Validation

- Five retirement contracts: three reproduced failures before removal, all five
  pass afterward. Three consumer contracts pass. The full declared `npm test`
  passes 1,641 checks, with zero failures, cancellations or skips. The normal test
  command includes retirement coverage.
- Final versioned `npm run build` separately succeeds and deploys only the allowed
  artifacts into Obsidian Plugin Test Vault. Hot Reload reloads GCM; targeted
  disable/enable after refreshing manifests verifies loaded 7.3.17 and API readiness.
- Actual foreground Live Preview character input has all eight active TPS consumers
  enabled. Both before/after samples contain 40 characters and 40 editor-change
  events with visible document, focused document and focused editor throughout.

The old synchronous search takes 79.9 ms on its first measured call and 63.8 ms
at the median, with a 60.8–79.9 ms range. Operation counts are reported separately
from these instrumented component timings. A repeated 20-character post-reload
burst also has zero inventories/searches, 247 application metadata calls, one raw
read, eight cached reads and one ordinary modification. The removed component
performs no reads or writes in either post-removal sample because it no longer
exists. Residual operations belong to core saving and other enabled consumers.

Native completion visibly offers the synthetic note after typing `[[`, and Enter
inserts its link. The synthetic body marker/frontmatter are preserved; the fixture
is archived directly, instrumentation is restored and the original leaf is restored.
All eight plugin saved-data hashes (including the absent Messager data file) and
the enabled-plugin file hash are unchanged. Outbound automation remains disabled.

## Limits and handoff

These are warm Mac test-host samples with temporary instrumentation. They do not
measure physical iPhone input, input-to-paint latency, process cold startup or
production performance. Other expensive TPS operations found by the audit remain
outside this focused release. Other feature retirements require the user's choice.

This public release contains the tested artifacts and is ready for the user's
BRAT pull. Production plugins are not directly deployed or reloaded by this task.
