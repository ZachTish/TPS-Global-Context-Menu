# TPS Global Context Menu 1.4.0

This minor release turns the exact-line task editor into a safe editor for the inline properties already attached to a task.

## User-visible changes

- Existing selector, date/time, recurrence, number, list, checkbox, and text properties appear below the task text with type-appropriate controls.
- Scheduled date, time estimate, and all-day state are edited together through the existing Scheduled picker. Recurrence continues to use the TPS recurrence picker.
- The compact property list scrolls independently when needed. Child pickers preserve the parent draft, and mobile controls retain the keyboard-safe overlay, sticky action row, safe-area padding, and 16 px input sizing.

## Reliability and compatibility

- Status remains owned by the task checkbox. TPS IDs, sync payloads, relationship carriers, completion/timestamp fields, and properties explicitly hidden or disabled in configuration are not exposed.
- Save re-resolves the current task line and applies the body plus only explicitly changed property keys in one atomic mutation. Untouched concurrent property additions, removals, and sync metadata survive; Cancel and no-op Save do not rewrite the line.
- Invalid numbers are rejected before mutation. Property values are never included in structured logs.
- Minimum supported Obsidian version: 1.10.0. Desktop and mobile are supported; no settings or data migration is required.

## Validation

- Focused task-editor, task-line, recurrence, mobile-overlay, and TypeScript checks passed. The complete declared release suite passed 284/284 tests.
- A separate production-mode build reported the final runtime unchanged after the suite deployment. All four source artifacts match the isolated test runtime byte-for-byte.
- Obsidian 1.12.7 was reloaded with **Reload app without saving** in `Obsidian Plugin Test Vault`. A TPS List task displayed Scheduled, selector, recurrence, list, number, checkbox, and text controls while hiding TPS identity/payload metadata. The Scheduled picker temporarily suspended the parent card and returned to the intact draft on Cancel.
- A live Priority edit saved only that property while retaining task text, Scheduled, and Time Estimate. The synthetic task was restored byte-for-byte afterward; a separate no-op Save left it unchanged. Runtime-owned `data.json` retained its pre-build SHA-256.

## Known limitations

- The isolated macOS test app cannot summon the iOS software keyboard; mobile geometry and interaction contracts are regression-tested, while final native-device confirmation remains separate.
