# TPS Global Context Menu 1.3.3

This patch keeps the mobile task quick editor and its actions above the iOS keyboard when Obsidian and WebKit temporarily disagree about the visible viewport.

## User-visible changes

- Opening a task from TPS List, TPS Table, Markdown, Calendar, Kanban, or Home on a phone keeps the compact editor inside the screen area above the software keyboard.
- Save, Cancel, and Open in note remain reachable while the keyboard is open.
- Delayed keyboard repositioning continues even if a virtualized Base rerender removes the original selected-row element while the editor is open.

## Reliability and compatibility

- The shared overlay utility now intersects the valid layout-viewport and `visualViewport` dimensions. This handles either API temporarily retaining its pre-keyboard height during iOS keyboard animation.
- Desktop anchored placement remains source-row-relative; detached-anchor fallback is limited to the compact mobile bottom-sheet route.
- Minimum supported Obsidian version: 1.10.0.
- No settings or data migration is required.

## Validation

- Focused task-editor and mobile-overlay suites: 47/47.
- Complete declared isolated release-snapshot suite: 268/268, including TypeScript and its build-only production bundle.
- A separate production-mode build deployed the exact isolated release snapshot to the test vault; `main.js`, `manifest.json`, `styles.css`, and `styles-ui.css` matched the runtime byte-for-byte, while runtime-owned `data.json` and recurrence state retained their earlier modification times.
- Obsidian 1.12.7 was reloaded with **Reload app without saving**. The existing Plugin QA TPS List rendered both synthetic task rows; clicking `Synthetic open task #qa` opened the exact `QA Task Sink · line 6` editor with Open in note, Cancel, and Save visible. Cancel closed the editor without modifying the QA note.

## Known limitations

- The isolated macOS test app cannot display the native iOS software keyboard. Automated viewport regressions cover the stale iOS geometry shown in the report; final device confirmation remains separate.
