# TPS Global Context Menu 4.1.2 — Inspect unresolved child links on request

Opening a note no longer schedules an unresolved child-link check after 800 ms. That check read the selected body and could offer to remove link lines during ordinary navigation, including native whole-note mode. The existing inspection and confirmation flow remains available through the new **Child links: Check unresolved links in current note** command. It reads only the selected Markdown note when invoked.

The independent **Render child-note links as checkboxes** setting continues to work in native and legacy modes. When disabled, note-open and other event refreshes skip its linked-row rendering, and switching it off clears already mounted Reading and Live Preview rows. Other menu and inline task controls keep their existing startup route. This is a backward-compatible patch: no note-content, settings-schema, writer, public API, or compatibility change. Minimum Obsidian remains **1.10.0**.

The exact artifacts below were tested in **Obsidian Plugin Test Vault** and are ready for the user's BRAT pull. Production was not changed.
