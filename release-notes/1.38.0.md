# TPS Global Context Menu 1.38.0

This backward-compatible minor release introduces the opt-in native Markdown record architecture used by the TishOS Native POC. Existing vaults stay on Legacy mode.

## Highlights

- Versioned native-record and task-record APIs with stable IDs, typed frontmatter, atomic updates, archive, and exact inline-task promotion.
- Native mode disables TPS-owned List/Table filtering, virtual Base embeds, line-row indexing, and automatic companion creation.
- Explicit asset records replace new hidden property companions; existing legacy data is left intact.

Minimum Obsidian: 1.10.0. Tested in the isolated test vault and ready for the user's BRAT pull.
