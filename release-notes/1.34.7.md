# TPS Global Context Menu 1.34.7

TPS Global Context Menu 1.34.7 fixes the remaining Reading View Linked-context scroll reset and closes the remaining strict Source-mode decoration paths.

## Reading View scroll stability

- Linked-context recovery listens for scrolling in capture phase on the Markdown view and learns Obsidian's actual scrolling descendant from the event target.
- A downward wheel gesture marks the view as away from the top before the browser updates `scrollTop`. Top-placement recovery is deferred during that frame instead of moving or recreating a host that can reset Reading View.
- Scroll state is scoped to the current note, follows a replaced scroller, and is released when the view or feature is closed.

## Literal Source mode

- Linked-subitem checkbox and property widgets no longer replace Markdown in strict Source mode.
- GCM's Calendar/Tasks/Mentions navigation and Daily Note navigation are removed in strict Source mode and return in Live Preview or Reading View.
- Source-mode detection uses the Markdown view state rather than depending on one optional CSS class.

## Compatibility and known limitations

- Backward-compatible patch with no new setting, public API, note rewrite, or schema migration.
- Top-placed linked context still waits until the same note returns to the top before applying a deferred source refresh. Existing panel content remains usable while deferred.
- Minimum supported Obsidian remains 1.10.0.
