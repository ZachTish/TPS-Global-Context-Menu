# TPS Global Context Menu 1.25.3

## Intent

Prevent false stale-task notices when a mobile Calendar Base status selection reaches GCM more than once before the first task-line write completes.

## Changes

- Coalesces concurrent status mutations for the same source task and destination checkbox state, so every duplicate caller awaits the original durable write.
- Routes quick-editor toggles, task status pickers, mapped context-menu choices, and custom mapped checkbox choices through the same guarded status writer.
- Emits a concise `status-write:duplicate-coalesced` diagnostic when logging is enabled.
- Preserves the existing compare-and-swap checkbox token check, live mapping-signature validation, checkbox-owned workflow cleanup, completion-date handling, and follow-up synchronization.

## Compatibility and migration

- Minimum supported Obsidian version: 1.10.0.
- No settings, note-data, or API migration is required.
- Duplicate semantic status mappings remain separate exact checkbox options.

## Validation

- Added a regression that submits the same mobile status mutation twice while its vault write is in flight and verifies that only one write starts, both callers share its result, and the registry clears after settlement.
- Passed the focused task-line context-menu suite, the complete declared test suite, TypeScript validation, and a separate production build.
- The exact release artifact was deployed to and reloaded in the isolated Obsidian Plugin Test Vault; runtime state was preserved.
