# TPS Global Context Menu 2.3.1

Daily-note creation no longer silently stops because an unrelated project or archived note contains malformed YAML. Navigator’s calendar and daily-note command use this shared provider, so updating GCM supplies the fix without a Navigator update.

## Behavior and safeguards

Invalid non-daily files are isolated from daily-note reconciliation and are never repaired, renamed, or rewritten. Malformed files with possible Daily identity still block mutation: date-shaped paths, cached Daily markers, raw Daily aliases, and escaped/aliased YAML remain conservative. Existing duplicate, conflicting-identity, unreadable-source, and target-occupancy checks remain intact.

This is a backward-compatible patch. No settings, API-version, schema, or note-data migration. Minimum Obsidian: **1.10.0**.

## Validation

- `npm test`: **1,154 passed**, zero failures or skips; includes TypeScript and production build.
- `npm run prepretest`: **125 passed**, zero failures or skips.
- Focused Daily Note creation/identity tests: **93 passed**; final identity rerun: **30 passed**.
- Separate final `npm run build`: passed, test-vault runtime unchanged from the validated artifact.
- Test plugin reloaded to 2.3.1. A provider call that returned null before the patch now created its synthetic note.
- Navigator’s real confirmation flow created and opened a Core-templated note while an unrelated mixed YAML mapping/list fixture remained invalid. The title/date tokens rendered, the template tag was removed, and reopening selected the same file without a second creation.
- Malformed fixture remained byte-for-byte unchanged. Temporary defaults were restored and synthetic notes were archived.
- UI QA used Core template tokens; Templater is not installed in the test vault. Existing automated Templater regressions passed.

Known limitation: malformed YAML containing incidental Daily markers or escaped/aliased content remains conservative and may need repair before daily creation. The plugin does not automatically correct malformed personal notes.

Tested in **Obsidian Plugin Test Vault** and ready for the user’s manual **BRAT pull**. This release has not been deployed to a production vault; production acceptance remains separate.
