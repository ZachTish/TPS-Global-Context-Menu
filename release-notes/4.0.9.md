# TPS Global Context Menu 4.0.9 — Property editors fit the pane

Custom property editors use one column when space is limited and additional columns when they fit. Controls wrap within the card, textareas stay inside the pane, and action buttons retain usable touch targets. The prior fixed two-column grid pushed Frontmatter Key and its Apply button beyond the settings pane.

All fields, actions, demand rendering, draft retention and save/migration ownership are preserved. No settings, schema, API or minimum-version change; no new runtime state or background work. Patch release; minimum Obsidian 1.10.0. Physical iPhone acceptance remains separate from desktop narrow-layout QA.

## Validation

Validation: 25 focused property/demand/visibility checks and all 1,435 declared tests pass with zero failures, skips or cancellations; TypeScript and the separate production build pass. Named reload confirms 4.0.9 in Obsidian Plugin Test Vault. Tested in **Obsidian Plugin Test Vault**, ready for the user's BRAT pull. Production has not been modified. This layout correction does not establish the broader 80% native-performance target.
