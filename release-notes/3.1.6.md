# TPS Global Context Menu 3.1.6

Backward-compatible rendering fixes; minimum Obsidian 1.10.0. Tested in Obsidian Plugin Test Vault and ready for the user's manual BRAT pull. Production was not deployed.

## Changes

- Reading view retains unchanged linked-item rows rather than removing/rebuilding every checkbox and property pill on each refresh. Changed rows are built off-DOM and swapped together; unchanged keyboard focus survives.
- Reading view reads the current preview document instead of stale hidden-editor text. Fallback mapping matches standalone native link destinations, avoids section-relative line-number confusion, and assigns each host once. Repeated links and nested cleanup have regression coverage.
- Live Preview compares every rendered field and action target. Changed widgets retain CodeMirror's mounted wrapper while updating all children and event handlers, fixing stale labels/pills from the former checkbox-only update.
- Give the linked-row editor extension precedence over native wikilink decorations. This fixes the reproduced case where a native metadata refresh covered the custom row with a blank replacement.
- No settings/default changes, API changes, note migrations or external automation changes.

## Validation

- `npm test`: 1,228 passing checks, including 11 new focused rendering checks.
- `npm run prepretest`: 148 passing checks. TypeScript and mandatory separate production build passed; deployment reported `target=test`.
- Final plugin reloaded with the vault name/path guard; installed artifacts match the tested source artifacts byte-for-byte. Persisted GCM settings stayed unchanged.
- Installed Reading-view fixture: 40 rows correctly mapped; all 40 DOM nodes and keyboard focus survived ten unchanged refreshes. A changed title/status refreshed its row while all 39 unrelated rows remained mounted. The metadata display check explicitly invoked the render refresh; it is not a latency guarantee for metadata event routing.
- Ten synchronous refresh calls measured a median about 9.6 ms on the final 40-row fixture versus about 18.7 ms on the initial 40-row fixture. These small local samples measure the linked-row service only, not whole-vault responsiveness. Baseline refreshes produced 4,800 child-list mutation records; unchanged refreshes after reuse produced zero child-list mutations in the earlier installed comparison. Final focus-inclusive observation retained every row (one surrounding attribute mutation).
- Installed Live Preview: title/status update retained the mounted wrapper, showed current content, and stayed visible after scrolling away/back. The blank-row reproduction failed before the precedence correction and passed afterward.
- Synthetic notes archived directly from Inbox; QA tabs/probes removed and original tab restored.

## Limits

This release targets linked-item rendering. It does not claim to optimize all Bases, Markdown embeds, or every typing/scrolling operation. The broader Source/Live Preview transition scheduling issue previously documented is not certified fixed. Physical iPhone acceptance and production installation remain separate.
