# TPS Global Context Menu 1.32.0

TPS Global Context Menu `1.32.0` adds typed batch property actions to selected TPS List/Table tasks and a guarded public bridge for multi-item Notebook Navigator drops.

## Selected task batches

- Multi-selected task rows share one **Change property** menu. Scalars replace, list/link/tag values add and deduplicate, list members can be removed, and typed checkbox, datetime, text, number, recurrence, selector, entity, and tag inputs retain their normal GCM behavior.
- Parent link-list fields are additive, so assigning another parent does not replace existing relationships.
- **Remove tag** operates on the union of tags across the selected tasks. The existing comma-separated tag addition flow remains available.
- Every batch re-resolves current task revisions and records only confirmed user mutations through Item History. A stale or ambiguous selection fails closed before the batch begins.

## Cross-plugin typed drops

- Desktop TPS List and TPS Table selections publish one or many transient exact task references for TPS Notebook Navigator 5.17.0.
- Dropping on a Navigator tag or concrete property-value row delegates to `plugin.api.itemProperties` v1. Configured lists add/deduplicate; configured scalars replace.
- Hidden, disabled, Folder, Kind, non-inline, empty-key, and incompatible targets are rejected without changing task lines.
- Ordinary file drops remain Navigator-owned. GCM's typed definition lets Navigator apply the same list/scalar behavior and route non-Markdown files through native companion properties.

## Compatibility and known limitations

- Backward-compatible minor release with additive `itemProperties` v1 and `itemPropertiesVersion` lifecycle metadata.
- No setting migration or bulk note rewrite. Existing APIs and task menus remain compatible.
- Task-line drag/drop is desktop-only. Task lines cannot be dropped on folders because a line has no independent source-folder identity, and empty property-key rows have no meaningful inline value to assign.
- Minimum supported Obsidian version remains `1.10.0`.
