# TPS Global Context Menu 1.40.1

This backward-compatible patch repairs a mobile editor-state mismatch that could make a note look like strict Source mode even though Obsidian retained a Live Preview state.

## Mobile Live Preview reliability

- A mounted strict-source editor now wins over a stale `source:false` flag for TPS rendering decisions. GCM therefore never overlays rendered properties, linked context, or inline replacements on literal Source Markdown.
- If the saved intent is Live Preview, GCM re-applies that state once without adding navigation history. The repair is rate-limited so a broken or transitioning editor cannot enter a remount loop.
- Explicit Source mode remains literal and is never changed. Reading View behavior is unchanged.

## Compatibility

- No settings, note, Base, schema, or public API migration.
- Minimum Obsidian: 1.10.0.
- Production is untouched. This release is validated only in the isolated test vault and is intended for the user's BRAT pull.
