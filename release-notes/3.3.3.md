# TPS Global Context Menu 3.3.3

A rejected or cancelled title edit could still rename the file: GCM ran a second filename update after the property writer returned without saving. The title action now uses the existing frontmatter writer as the sole owner of title-driven filename updates, and stops before success notifications when no write was applied. This is a backward-compatible patch with no new settings, state, watcher, repair, migration or dependency.

Successful edits retain Auto-rename, filename collision checks and Daily/native-record filename ownership. Auto-rename off still changes only the title. Existing mismatched notes are not remediated. Navigator's separate native **Rename note** action is unchanged; the exact action/rejection behind the user's report has not yet been confirmed.

## Validation

- Reproduced on installed 3.3.2 in Obsidian Plugin Test Vault: submitting `After` in Edit Title on a synthetic note with a rejected frontmatter write changed the filename to `After.md` while its title remained `Before`.
- Two regression checks fail on the old implementation: a rejected write renamed the file, and successful title edits invoked the filename writer twice.
- All 36 focused checks, 1,236 full-suite checks and 160 additional checks passed, with no failures or skips. Full suite includes TypeScript/build; a separate final production build deployed only to the test runtime.
- Named test-vault GCM reload verified installed 3.3.3. The same rejected Edit Title submission preserved both path and source bytes. A normal Edit Title submission produced `Valid after.md` with `title: Valid after` and unchanged body. Regression tests also cover Auto-rename off and write exceptions.
- GCM persisted settings stayed byte-identical. Synthetic fixtures were retired directly to `_archive/QA-rename-20260925`; no invalid fixture was left behind. No production access or outbound automation.

Minimum Obsidian: **1.10.0**. Tested in the test vault and ready for the user's BRAT pull. Physical iPhone acceptance and production installation remain separate.
