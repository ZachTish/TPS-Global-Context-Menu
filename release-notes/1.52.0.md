# TPS Global Context Menu 1.52.0

- Status and unrelated property edits no longer normalize untouched date fields. A shared complete-value formatter preserves explicit UTC/offset suffixes and fractional seconds; general frontmatter edits, scheduled bulk edits, subitem dates, and no-Moment completion/activity fallbacks cannot turn 16:00Z into local 16:00.
- Shared schedule reads and TPS List date chips preserve the complete instant before legacy text/range parsing. UTC, offset, date-only/local, Date objects, seconds/milliseconds, and daylight-saving repeated hours have behavioral coverage; negative UTC offsets are not mistaken for time-range separators.
- Native-record API v6 adds `capabilities.calendarTemplateRecords: true`. An exact Controller `calendar:v1:<16 base64url characters>:<27 base64url characters>` identity supplies the internal calendar route without requiring public `kind`. Its file retains an optional template/user-owned `kind`; inspection/handles still report structural `calendar-event`, while `frontmatter.kind` contains only the authored optional value.
- Canonical calendar creation and identity-plan creation accept an optional exact `body`, committed atomically with the one `tpsId` and public fields. The plan binds that body as well as the identity, kind route, and path. Wrong routes, copied/duplicate IDs, changed bodies, invalid kind types, and unsupported non-calendar body requests fail closed. Existing calendar kinds/bodies survive update, rename, re-identification, and consolidation.
- This is an additive capability release. Other native kinds keep their established required kind behavior, and Calendar-created non-Controller records remain unchanged. No extra identity, private registry, automatic kind cleanup, or guessed correction of old timezone-less dates is introduced. Install GCM 1.52.0 before Controller 0.15.0; Calendar 0.10.3 consumes the optional-kind contract. Minimum Obsidian remains 1.10.0.
- Final validation and artifact hashes are recorded in `release-notes/1.52.0.md`.

## Validation

Validation: full declared suite 1,248/1,248, TypeScript, and a separate production build. Subitem inheritance preserves bare date-only values (all-day semantics) as well as UTC/offset instants. Obsidian 1.14.0 test-vault command QA created two canonical calendar notes (no template/no public kind; static template/custom kind/body), completed them through the actual frontmatter service, and re-synced without duplicates or changed completion/time/body/kind. Both rendered at 11:00–11:30 America/Chicago in Calendar. Test plugin/full test-vault reload confirmed final versions; no outbound feed was contacted. In-memory QA settings were restored; persisted GCM/Controller settings and recurrence session remained byte-identical. An old malformed archived synthetic fixture was temporarily excluded and restored byte-for-byte. Test artifacts are deployed only to the isolated test vault; this release is ready for the user's BRAT pull, not a production deployment.
