# TPS Global Context Menu 1.35.2

## Intent

Stop TPS List rows and scroll position from jumping, clipping, or visibly rematerializing during routine scrolling and refreshes, and make archive-folder filters apply to the complete folder subtree.

## Changes

- TPS List captures and restores the outer Bases view—the element that actually owns scrolling—instead of its non-scrolling inner content wrapper.
- Scroll restoration is synchronous with the completed render. The previous delayed animation-frame replay could no longer override a newer user scroll.
- Removed `content-visibility: auto` and its fixed 24px intrinsic placeholder from variable-height List rows. Wrapped titles and configured property stacks retain their real height throughout scrolling.
- Folder equality is prefix-aware in the shared TPS List/Table filter evaluator. `folder is _archive` matches `_archive`, descendants such as `_archive/QA`, and prefixed archive folders such as `_archive-old`; its `is not` inverse excludes all of them.
- The same folder behavior applies to `folder`, `folderPath`, and `file.folder` in expression-string and object filters. Other filtering, grouping, sorting, progressive indexing, selection, drag/drop, editing, and row semantics remain unchanged.

## Compatibility and migration

- Backward-compatible patch; minimum supported Obsidian remains 1.10.0.
- No settings, Base files, note data, commands, or public APIs change. Existing archive filters begin excluding nested descendants as users expect; no authored query migration is needed.

## Validation

- The complete declared suite passed (1,106 tests), including the shared TPS query-plan/filter matrix, TPS List rendering and scroll-owner regressions, TypeScript validation, and the package build gate.
- A separate final production-mode build passed and atomically deployed the exact release bundle to the isolated test vault. Source and runtime artifacts match byte-for-byte.
- Test-vault UI QA opened a TPS List with 56 rows and a production-shaped folder filter. The active Inbox task rendered, while tasks in both `_archive/QA` and `_archive-old` were absent. The temporary Base and task fixtures were removed afterward.

## Known limitations

- TPS List intentionally renders its complete current result set rather than applying browser row virtualization. Very large result sets may use more initial layout work, but their geometry remains deterministic.
