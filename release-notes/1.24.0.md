# TPS Global Context Menu 1.24.0

TPS List grouping, selection, and checkbox presentation are now consistent with the task data and Obsidian UI they represent.

## Changes

- Task grouping by Tags reads task-local Markdown hashtags plus `tag`/`tags` inline fields, deduplicates them, and does not inherit source-note tags.
- A new per-view **Grouping → Items without a group** setting places the unmatched group at the top or bottom. Existing views default to the bottom.
- TPS List context menus wait for range/Cmd/Ctrl selection synchronization before opening, restoring multi-task batch actions.
- TPS List uses Obsidian's checkbox sizing and radius variables so task controls align with native checkboxes and surrounding rows.

## Compatibility and migration

- Minimum Obsidian version: 1.10.0.
- No note schema or global plugin setting changes are required.
- The new unmatched-position choice is stored in the individual Base view configuration.

## Validation

- Focused TPS List regressions cover task-local hashtags, inline tag combination, per-view unmatched placement, asynchronous multi-selection handoff, and checkbox CSS.
- The complete declared test suite, TypeScript check, and separate production build were run against the final versioned artifact in the isolated Obsidian Plugin Test Vault.
- Visual UI automation was not used because the available Obsidian window was not verified as the isolated test vault; production was not inspected or modified.

This public release is tested in the isolated test vault and ready for the user's BRAT pull. SHA-256 hashes are listed on the GitHub release after the final artifacts are built.
