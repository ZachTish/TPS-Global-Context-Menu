# TPS Global Context Menu 1.46.0

**Create task** now defaults to a standalone Native Markdown task record instead of using today's Daily Note as its parent.

## Configurable task parent default

- **Workflows → Tasks → Create task default parent** offers **Standalone (no parent)** and **Today's Daily Note**. Missing or invalid saved values normalize to Standalone.
- The Native creation dialog shows the current parent choice and can switch between Standalone, today's Daily Note, and another Markdown note before submission.
- Opening, canceling, or switching the dialog to Standalone never creates today's Daily Note. The Daily Note choice is resolved only after a task is submitted.

## Standalone and linked creation

- Standalone creates and opens one `kind: task` record directly. It writes no source checkbox, Daily Note link, `sourcePath`, `sourceLine`, or parent metadata.
- Choosing today's Daily Note or another parent retains the existing guarded promotion route: the parent receives the stable task-record link and the task record keeps its source location.
- Legacy architecture still creates inline checkbox tasks and therefore always requires a containing note.
- Native/Legacy mode and checkbox-to-status mapping are revalidated at the final write boundary. A settings change during asynchronous folder preparation fails closed without creating a stale task record.

This is a backward-compatible minor release. It performs no note or record migration, changes no command or public API contract, and retains minimum Obsidian 1.10.0.
