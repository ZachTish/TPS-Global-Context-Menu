# TPS Global Context Menu 1.35.5

## Intent

Make TPS List and TPS Table settle predictably during opening and filter editing, expose deterministic grouping by the containing file path, and make Reading View line taps menu-first.

## Changes

- List and Table share one resettable trailing refresh boundary, so a burst of Base/controller/index events produces one replacement render.
- TPS List no longer performs its former unconditional second open render. It waits for the persisted Base definition and keeps the last stable surface connected while asynchronous task rows are prepared.
- Progressive index batches update lightweight progress state rather than sorting and rebuilding the complete DOM for every batch. A complete generation is published atomically, and superseded generations stop immediately.
- Both custom-view option panels now expose **Group by** and **Group order**.
- `file.path` grouping uses the logical containing Markdown path for note, task, bullet, and heading rows, with deterministic ascending or descending ordering.
- Reading View task-text taps open the full task context menu. Plain bullet taps resolve the exact source revision and open line actions for editing, tags, configured properties, navigation, and guarded deletion.
- Checkbox, link, inline-property, and button interactions remain native; Live Preview and custom Base row clicks retain their existing editor behavior.

## Compatibility and migration

- Backward-compatible patch; minimum supported Obsidian remains 1.10.0.
- No setting, Base, note, property schema, or public API migration is required.
- Existing serialized `groupBy` objects remain supported; the new visible options persist the ordinary property plus direction fields.

## Validation

- The complete declared `npm test` suite passed against the final versioned source, including its production build.
- A separate final `npm run build` passed and confirmed the deployed test-vault runtime was byte-identical.
- Focused List/Table/Reading regressions passed: 142/142 for refresh, filtering, grouping, and line interactions; the final Reading-specific matrix passed 56/56.
- Test-vault UI QA on Obsidian 1.13.7 confirmed TPS List and TPS Table remained unchanged after their settling window, the Table filter editor remained stable, and `file.path` produced deterministic containing-note groups.
- Reading View QA confirmed task text opened the task context menu and the exact live rendered bullet opened its edit/tag/property/navigation/delete menu. The synthetic QA note was removed afterward.

## Known limitations

- A cold view still needs to index uncached candidate Markdown files before all synthesized rows are available. It now reports progress without repeatedly replacing the result surface.
- Manual saved lane ordering remains authoritative for specifically reordered groups; otherwise configured ascending/descending order applies.
