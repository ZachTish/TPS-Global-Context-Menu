# TPS Global Context Menu 1.19.0

## What changed

- TPS Notebook Navigator's normal file context menus now receive applicable GCM-owned actions through Navigator's existing public file-menu API. This includes Notes plus PDFs, Canvas, Bases, drawings, media, and other file-backed Type rows; no GCM action or setting is redefined in Navigator.
- Single and multi-selection are exact and transactional. A missing, duplicated, replaced, or mismatched file cancels the whole GCM extension; ambient editor and File Explorer selection are never consulted.
- Multi-selection exposes only batch-safe GCM actions. PDF writing, relationships, attachment embedding, and time tracking remain single-file commands instead of silently changing the first selected item.
- Navigator's native Title/Rename, Tags, and Delete actions are not duplicated. On all-Markdown selections, GCM suppresses only its standard `tag`/`tags` property; custom tag-list fields remain available, and non-Markdown selections keep their applicable configured properties. GCM's existing legacy note-row bridge remains available for older compatible hosts, while task, bullet, and heading rows keep their exact-line menus.
- Property-row visibility choices now write the matching `Inline visibility` setting. **Always show even when empty** can no longer be defeated by a stale inline override or disabled inline participation flag, and **Use property visibility** restores inheritance.
- Direct visibility choices rerender every mounted GCM Properties panel—including Markdown, Bases/hover, and editable Base-link previews—before the settings save completes. A failed/stale renderer cannot block persistence or the remaining panels. Ordinary metadata refreshes still defer structural changes while the editor is active.

## Compatibility and migration

- Backward-compatible minor release; no settings or note-data migration.
- Minimum Obsidian version: 1.10.0.
- TPS Notebook Navigator 5.4.0 already exposes the required API and needs no companion update.
- The public GCM API versions are unchanged.

- Focused visibility coverage includes global/inline/context precedence, surface participation gates, global hiding, inherited mode, always/never patches, missing Priority inclusion before a delayed save, unchanged context visibility, one-pass mounted-view refresh, throwing-renderer isolation, collapsed-state ownership, preview-surface routing, and the existing typing-stability contract.

## Known limitations

- Navigator's public file-menu extension facade exposes item insertion but not separator insertion. Navigator brackets the GCM contribution as one group, and GCM item section metadata remains intact.
- TPS Notebook Navigator must be new enough to expose `menus.registerFileMenu(...)`; compatible older versions continue to receive only the legacy note-row bridge.
