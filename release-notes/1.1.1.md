# TPS Global Context Menu 1.1.1

Task quick editing is clean again, and multi-line Home captures now timestamp each top-level item instead of only one line.

## User-visible changes

- TPS List and TPS Table task quick editors show task text and visible `#tags` without exposing inline `[property:: value]` fields or hidden TPS JSON carriers.
- Saving an edit keeps every current source-line property and TPS payload attached. A concurrent metadata update wins over the editor's opening snapshot, and an unchanged save preserves the exact line.
- Home Quick Capture adds the same capture time to every top-level bullet, task, or plain line in one submission.
- Indented children and continuation lines stay nested beneath their parent and do not receive a separate timestamp.
- The timestamp rule is shared by the Markdown-aware command flow and the embedded/mobile capture formatter and preview.

## Compatibility and migration

- Minimum supported Obsidian version: 1.10.0.
- No settings or data migration is required.
- Existing task properties, hidden sync identity, associations, and tags are preserved.

## Validation

- Focused capture/task-editor and task-metadata suites: 72/72.
- Complete declared suite: 249/249.
- TypeScript validation and the required separate production-mode build passed.
- The final source artifacts are byte-identical to the isolated test-vault runtime.
- Obsidian 1.12.7 was reloaded with **Reload app without saving**. UI verification confirmed the task editor hid ordinary inline fields and the hidden JSON carrier while keeping the visible tag; an edited Save retained duplicate and substring-overlapping properties in source order.
- A Quick Capture UI submission wrote the same time to two root lines and no time to their nested child. The disposable Daily Note was moved directly to `_archive` after verification.

## Known limitations

- Inline properties are intentionally not editable from the task quick editor; use the existing property controls or source note when a property value itself must change.
- Quick Capture continues to reject Markdown headings as it did before this release.
