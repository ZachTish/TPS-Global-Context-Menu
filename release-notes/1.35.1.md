# TPS Global Context Menu 1.35.1

TPS Global Context Menu 1.35.1 keeps frontmatter out of Live Preview's Select All range while preserving literal full-file selection in Source mode.

## Changes

- `Ctrl+A` / `Cmd+A` in Live Preview now selects from immediately after a complete YAML frontmatter block through the end of the document.
- The body boundary supports LF and CRLF files, UTF-8 BOMs, `---` and `...` closing delimiters, and empty note bodies.
- Strict Source mode continues to use Obsidian's native Select All behavior and includes YAML frontmatter.
- Missing, malformed, or unterminated frontmatter fails closed to native selection rather than risking an incorrect partial selection.

## Compatibility and migration

- No setting, command, public API, note format, or persisted-data migration is introduced.
- Minimum supported Obsidian version remains 1.10.0.

## Validation

- The complete declared suite passed with zero failures, including the new Live Preview selection boundary and existing strict Source-mode integrity regressions.
- A separate production-mode build passed and deployed byte-identical `main.js`, `manifest.json`, `styles.css`, and `styles-ui.css` artifacts to the isolated test runtime.
- After reloading the isolated Obsidian Plugin Test Vault, a synthetic frontmatter note verified that `Cmd+A` in Live Preview selected only its body. Switching that same note to Source mode verified that native Select All included the complete YAML block and body. The synthetic note was moved to the test-vault archive after verification.
