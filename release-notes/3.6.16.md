# TPS Global Context Menu 3.6.16

A saved title containing filename-invalid characters could briefly become its sanitized filename while Obsidian updated incoming links. The existing title refresh now runs in a microtask after the committed Markdown rename event, allowing synchronous core view listeners to finish first. It no longer waits for the full link-rewrite promise. Ordinary folder moves do not request this refresh.

The existing metadata renderer keeps current-source display, active-editing and strict-source guards. Controller-only filename-to-title writes and companion bookkeeping retain their authority. This backward-compatible patch adds no persisted setting, API version, migration, cache, watcher, timer, retry or repair. Link rewriting still completes before a save reports success. Minimum Obsidian remains **1.10.0**.
