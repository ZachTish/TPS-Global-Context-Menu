# TPS Global Context Menu 8.2.0 — Current-day accent and responsive daily navigation

Daily navigation now highlights the actual current day using Obsidian's
Appearance accent. The opened note's date stays centered above Today even when
it is a different day. Today uses the same accent and remains available when
the current day is outside the visible range.

## Configuration and behavior

- **Appearance → Daily Note Navigation → Visible day buttons → Automatic (up
  to five)** shows five centered dates when space permits, three in narrower
  panes, or one in very tight spaces. Text-size settings affect how many fit.
- Existing fixed counts 1–7 are preserved. Select Automatic to enable the new
  responsive behavior. New/unset settings default to Automatic. The existing
  numeric `dailyNavDayCount` key uses `0` for Automatic; there is no migration
  or additional settings key.
- All ranges are relative to the opened date. Seven days previously showed an
  ISO week; it now follows the same centered range as other odd counts. Even
  fixed counts retain their left-biased range.
- Mobile dates appear above the Today controls with 36px-tall buttons. Scoped
  CSS container queries handle resizing without a JS resize observer or note
  processing.
- The fallback beneath a note title stays centered above Today. Blank space
  around floating controls passes clicks through to the note underneath.
- A single local-midnight timeout while the strip is mounted updates today's
  highlight; it respects daylight-saving transitions. Focus/resume uses the
  existing refresh queue. Disable, detach and unload cancel owned work.
- Note identification, template/creation/opening routes, the optional Today
  setting and note data retain their existing owners.

This is a minor release for a backward-compatible configurable feature.
Minimum supported Obsidian is **1.10.0**, unchanged.

## Validation and limits

Tested in **Obsidian Plugin Test Vault**, Obsidian **1.14.4** on Mac, with all
eight active TPS consumers enabled. No outbound automation was enabled.

- Final `npm test`: **1,719 checks passed**, zero failures/skips.
- Final supplemental `npm run prepretest`: **322 checks passed**, zero
  failures/skips. Includes identity, source preservation and template guards.
- TypeScript and the separate production-mode `npm run build` passed and
  deployed only to the test vault. Targeted manifest-ID reload confirmed 8.2.0.
- Foreground native UI inspection verified Thursday centered while Friday
  was today's accent date, correct date/previous/Today button requests and a
  mobile date strip above Today. Installed geometry checks passed five/three/
  one layouts at 100%, 150% and 200% text scales, plus fixed 1/3/5/7. No
  Automatic-cell overflow occurred; centering error stayed below 0.004px.
- Live accent-variable changes updated both highlighted buttons without a
  rerender. Before/after 100 unchanged owner refreshes used zero raw/cached
  note reads, inventories or write attempts; 100 width changes retained the
  same DOM and midnight timer.
- Installed fallback checks confirmed under-title centering and that blank
  floating space passes clicks through while its buttons remain interactive.
- The actual native settings selector preserved a fixed three-day setting
  and accepted Automatic then three days, with one save/refresh per selection
  in an isolated draft. Real settings remained unchanged, and temporary QA
  overrides/UI were removed.

Presentation QA used the actual installed owner, DOM and CSS with temporary
leaf/date/opening facades. Click requests were recorded without creating
notes. Mobile layout/class and text-scale QA ran on Mac; physical iPhone
validation remains pending. These counts do not establish startup speed or
production performance. No production deployment or note remediation occurred.

The public numeric release is ready for the user's **BRAT pull**. Production
installation and user acceptance are separate steps.
