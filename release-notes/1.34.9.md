# TPS Global Context Menu 1.34.9

TPS Global Context Menu 1.34.9 makes bottom-placed Linked context persistent while scrolling Reading View.

## Persistent Reading View mount

- Reading View no longer mounts the Linked-context footer inside Obsidian's virtualized `.markdown-preview-sizer`.
- The footer is now a GCM-owned direct child of the stable Markdown preview root. Routine section virtualization therefore leaves the same panel DOM and component connected instead of temporarily removing and reconstructing it.
- Duplicate stable footer hosts are removed defensively. Existing bounded recovery remains for actual note, mode, or view-root replacement.

## Compatibility and known limitations

- Backward-compatible patch with no new setting, public API, note rewrite, ordering change, or schema migration.
- This patch addresses the Reading View footer detachment path. Live Preview retains its separate stable mount outside CodeMirror content.
- The panel naturally scrolls offscreen with note content; persistence means it remains mounted and does not flicker, disappear, or rebuild as Reading View virtualizes sections.
- Minimum supported Obsidian remains 1.10.0.
