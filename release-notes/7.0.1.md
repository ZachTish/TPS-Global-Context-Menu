# TPS Global Context Menu 7.0.1 — Keep kind-list writes unambiguous

GCM now removes configured legacy classification tag aliases when writing a record to a configured kind-list value. The aliases are derived from record types sharing that list value; unrelated manual tags stay in place. A conflicting tag or kind-list value still stops the write. This lets a Finance investment transaction with an old ordinary-finance tag become a valid kind-list note on its next explicit update. Navigation and display do not change notes, and existing notes still require the separate one-time vault migration.

This backward-compatible patch changes no saved setting or API shape. Kind paths, property keys, and aliases remain editable in GCM settings; no taxonomy is built into the writer. Minimum Obsidian remains **1.10.0**. Finance legacy investment updates also require Finances 2.1.1.
