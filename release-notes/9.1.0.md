# TPS Global Context Menu 9.1.0 — Markdown checkbox marker menu

Whole-note mode now offers a small marker menu when you right-click a native
Markdown checkbox or hold it for 550 ms. Choose `[ ]`, `[x]`, `[/]`, `[?]`, or
`[!]`, or enter a custom single-character marker through the existing modal.
Ordinary clicks continue to use Obsidian's checkbox behavior.

Configure the ordered list under **Workflows → Tasks → Markdown checkbox menu
choices**. Enter one value per line and choose Apply. The new additive
`checkboxMenuStates` array is independent of note statuses; an intentionally
empty array keeps only Custom. Invalid drafts do not save. Existing settings
routes, disclosures, defaults and API contracts are preserved. Minimum Obsidian
is **1.10.0**; this is a minor release for an additive interaction and setting.

Only the marker character changes. Editor actions preserve unsaved text and
native undo. Reading View uses core section-relative source positions and
Obsidian's atomic file process boundary. Stale lines, deleted/replaced files and
queued renames cannot redirect an update. Fences, code, frontmatter, comments,
HTML, embeds and plugin-owned checkbox controls are protected. No inline
metadata, note-status synchronization, completion timestamps, recurrence,
history, recovery, scan, watcher or background task is enabled by this feature.

Touch movement and multitouch cancel pending holds. A menu that has opened
consumes duplicate native context-menu events and the following release click,
even after a long hold, movement or a second finger. Unload cancels its pending
timer and prevents stale menu callbacks from opening a modal or writing.

  The synthetic Inbox note was archived and its original note view restored.
- Handler counts: Reading action 1 cached preflight + 1 atomic process;
  editor action 1 replaceRange and zero reads/processes; 100 identical choices
  zero reads, processes or editor replacements. No legacy writer was called.
  Integrated installed samples included existing consumer reactions: Reading
  2 raw/12 cached reads and 1 process; editor 1 raw/7 cached reads and 1
  replaceRange with zero processes. These are Test-vault operation counts,
  not production or cold-start performance claims.

Special marker appearance depends on the active theme. Source Mode has no
rendered checkbox widget; edit Markdown normally there. Unsupported renderers,
embedded previews and plugin controls keep their existing owners. Physical
iPhone verification remains for device testing; simulated touch checks are

Tested in the isolated test vault and ready for the user's BRAT pull.

settings and runtimes were not changed.
