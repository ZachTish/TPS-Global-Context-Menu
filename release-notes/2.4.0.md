# TPS Global Context Menu 2.4.0

The shared Daily Note classifier now accepts `kind: note` together with `noteKind: daily`. Both properties are required for this new route, with case-insensitive keys/values and trimmed whitespace. Existing kind/type/tag aliases and path-based recognition remain supported.

The pair participates in canonical and named-note lookup, legacy reconciliation, current-byte validation, navigation, and unscheduled task-date inheritance. Creation preserves the template's authored pair. A usable date still comes from the existing configured path or scheduled/title metadata.

Incomplete pairs do not supply new Daily identity. Conflicting task/workout/calendar kinds, mixed identities, conflicting dates, and malformed/unreadable source guards remain in place. No general subtype hierarchy, saved-setting migration, automatic note rewrite, or public API version change. Add the pair to a note or your configured Daily Notes template; existing defaults are unchanged.

Calendar 0.14.0 adds matching Scheduled-section placement for explicitly selected paired notes. Navigator consumes this GCM classifier without needing a new Navigator release.

This is a minor release because it adds backward-compatible two-level Daily Note support. Minimum Obsidian remains **1.10.0**.
