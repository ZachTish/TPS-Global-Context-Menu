# 2.5.0 — Shared note creation opening

New note creation now uses one GCM preference across native Bases, TPS Calendar, TPS Notebook Navigator, and covered GCM creation actions. Native Bases no longer have to open an iPhone tab before the selected outcome is applied.

- Configure **Menus & surfaces → Note opening → After creating a note**: Editable preview, Open note, or Stay in current view. Open destination controls current/new tab and the preview's Open button.
- Existing Calendar/Navigator opening preferences migrate once, without modifying their settings. Explicit opening destinations remain overrides; background imports remain silent.
- New-note previews support naming, body editing, properties, guarded save/close, rename-error recovery, and automatic path updates after naming rules run. Mobile controls use 44px targets and the existing keyboard-aware overlay.
- A narrowly scoped native-menu adapter preserves folder/template/default processing and stops only its post-write native presentation. It does not replace the real FileManager or patch all vault creates/openFile calls. Changed/unsupported native contracts retain native behavior.
- Additive `api.ui` capabilities support consumer handoffs. Update Calendar to 0.15.0 and Navigator to 6.3.0 for their integrations.

Validation: 1,166 full-suite checks plus 126 additional checks passed; separate production build, test-only deployment, reload and live embedded Table/Calendar/Navigator checks passed. Tested preview rename/body persistence, a duplicate-name failure, automatic renaming, stay, keyboard create/open-new-tab, property defaults, template metadata, settings handoffs and preserved tabs. Reprepared dependency caches produced byte-identical artifacts. Test preferences were restored and synthetic fixtures archived.

Known limitations: physical iPhone acceptance remains pending; iOS may require tapping the title/body to raise its keyboard after asynchronous creation. Core New note, independent third-party/Templater commands and legacy inline task/line creation keep their own workflows. Native interception is capability-checked against the inspected 1.14 native contract; unsupported versions preserve Obsidian behavior.

Backward-compatible minor feature release. Minimum Obsidian: **1.10.0**. Tested in **Obsidian Plugin Test Vault**, ready for the user's BRAT pull. This release has not been installed in production by the agent.
