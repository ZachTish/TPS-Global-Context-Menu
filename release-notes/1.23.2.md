# TPS Global Context Menu 1.23.2

This patch restores complete GCM bulk actions for large selections in the normal Notebook Navigator when its virtualized list mounts only the visible subset of selected rows.

## Changes

- GCM can recover the full selection from Notebook Navigator's live selection state.
- Recovery must resolve exactly the selected count reported by Navigator's native menu and must contain the right-clicked file.
- Persisted selection storage is excluded from this recovery path, and any mismatch keeps the existing scoped warning instead of applying an unsafe partial or inflated selection.
- No settings or note-data migration is required.

## Validation

- Focused virtualized-selection, menu integration, and existing selection-intent regressions.
- Complete declared test suite and mandatory separate production build with test-vault runtime deployment.
- Minimum supported Obsidian version: 1.10.0.

Tested in the Obsidian Plugin Test Vault and ready for the user's BRAT pull. Production is not modified directly.
