# TPS Global Context Menu 11.0.0 — Remove inert menu and legacy options

Twenty-six unused preferences are removed from the typed settings and defaults. This includes old automatic rename/title/folder writers, retired checklist/archive/daily-line settings, three ineffective per-view switches and native-menu ordering, and sizing/sync fields that only saved a value. The UI removes **Right-click menu placement**, **Enable in specific views** and nine nonfunctional sizing sliders. Fixed CSS defaults and user CSS overrides remain; no new style owner is introduced.

Working floating-menu position/offsets, daily navigation count and resting opacity remain. Reset appearance retains its position/offset action with accurate copy. Appearance edits use one existing settings save instead of calling it twice. The existing legacy-stripper removes the inert keys in memory, and the existing fresh save boundary omits only this newly retired set while retaining unrelated/opaque legacy state, storage aliases, migration markers and concurrent preferences. Note writers and property migrations no longer carry the retired checklist fields. The five destinations remain **Properties** (default), **Menus & surfaces**, **Workflows**, **Appearance**, **Advanced** with unchanged current routes/disclosure depth; misleading Controller appearance-sync copy is removed.

## Compatibility and migration

This is a major release because legacy persisted settings are removed from the supported configuration contract. Minimum Obsidian remains **1.10.0**. Existing functioning settings, commands and workflows retain their owners. Retired keys are omitted by existing settings-save paths; no new startup save, note rewrite, watcher, poller, repair loop or cleanup service is introduced. Credentials, execution state and migration markers remain protected.
