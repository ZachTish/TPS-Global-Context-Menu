# TPS Global Context Menu 1.44.2

This backward-compatible patch keeps linked task and child-note rows inside the mobile Daily Note viewport.

- Native-record storage identity tags are no longer presented as editable user-tag pills. GCM recognizes current and readable legacy tag-mode prefixes through the same storage profiles that resolve records; property-mode profiles and ordinary user tags remain visible.
- Scalar and list tag syntax share the same whitespace/comma tokenization as native-record resolution, so filtering an identity cannot accidentally hide a neighboring user tag.
- Reading View and Live Preview rows now wrap within the Markdown content width. Long titles, tags, selectors, and property values truncate locally instead of widening the entire note, while their complete values remain available through accessible labels and hover titles.
- Linked titles and property pills are keyboard reachable and operable. Base embeds keep their own independent horizontal scroller.

This changes presentation only. It does not rewrite notes, tags, record identity, settings, schemas, commands, or public APIs. Minimum Obsidian remains 1.10.0.
