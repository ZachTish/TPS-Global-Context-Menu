# TPS Global Context Menu 1.6.2

This patch makes custom-field Selector and List options reliably durable while their settings editor remains open.

## User-visible changes

- Every change in a custom field's **Manual options** or **Manual suggestions** textarea continues to save immediately.
- Typing more text after a previous settings write completes no longer leaves later characters visible only in the open editor.
- Closing and reopening settings—or reloading Obsidian—retains the complete saved option list.
- The same repair protects other nested custom-field and rule editors from becoming detached after an immediate save.

## Implementation

- Successful settings writes no longer replace live nested objects when the persisted value is identical to the requested snapshot.
- Genuinely newer synchronized top-level values are still reconciled into the running plugin.
- A newer in-memory edit made while an earlier request completes remains authoritative and is not overwritten.
- Key additions and removals remain presence-aware.

## Compatibility and migration

- Minimum supported Obsidian version: 1.10.0. Desktop and mobile are supported.
- Existing custom-field definitions and saved settings require no migration.
- No manual Save button was added because settings controls remain immediate-save.
- GitHub Actions standalone builds remain unavailable because this contained layout imports the adjacent shared deployment helper.
