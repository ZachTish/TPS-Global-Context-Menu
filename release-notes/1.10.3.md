# TPS Global Context Menu 1.10.3

## What changed

- The generic entity index now rebuilds once at Obsidian's authoritative initial metadata-resolution boundary, repairing a partial startup cache even when an early Base or picker already marked the index ready.
- An active task/bullet/heading line scan restarts after that repair, so note and line Kind entities remain complete without duplicates or ghost records.
- Empty configured TPS Table Selector, Accepted-Kind, Tags, and Scheduled cells retain property ownership and open their editor rather than the containing note. This release includes the cell-ownership correction introduced in 1.10.2 for installations updating from 1.10.1.

## Compatibility and migration

- This is a backward-compatible patch release.
- No settings or note-data migration is required.
- A relational dropdown still requires the custom property to set **Accepts kind**. Unconstrained text/list fields intentionally retain row navigation.
- Minimum supported Obsidian version: 1.10.0.

## Known limitations

- The Kind identity property itself is not an inline relationship editor. Use **Accepts kind** on the relationship property that should offer constrained note and line choices.
- Existing out-of-Kind links remain stored and visible; the constrained picker governs new choices.
