# TPS Global Context Menu 7.3.6

Backward-compatible performance fix for conflict-aware native-record snapshots.
Diagnostic IDs are collected in one pass over each existing ownership index,
using a lookup discarded when the snapshot returns. Mapping keys are resolved
once for the diagnostic batch. Previously every conflict rescanned both full
identity indexes, making a large conflict set disproportionately expensive.

Returned record identities, conflict path/ID ordering, kind order, detached
frontmatter, source verification, strict default snapshots and mutation guards
are unchanged. No conflict repair, note write, setting, persistent cache,
watcher or API change is introduced. This supports Controller 3.1.4's reuse of
the existing conflict-aware snapshot without slowing conflict-heavy vaults.

## Validation

- Before-failing regression: 5,050 synthetic notes, 2,550 conflicts, three warm
  snapshots; identity-index entry visits drop from 32,147,700 to 22,653. Complete
  records and diagnostics remain identical, with zero source reads and six
  mapping-profile reads across the three snapshots.
- Coverage includes duplicate owners, blocked/valid ownership overlap, multiple
  reserved IDs on one path, configured kind keys, and detached nested metadata.
- All 138 focused native-record tests pass, with no failures or skips.
- Final versioned `TPS_NO_DEPLOY=1 npm test`: 1,554 passed, zero failures or
  skips. Explicit supplemental `npm run prepretest`: another 210 passed, zero
  failures or skips. Separate production-mode build passed and deployed only
  to Obsidian Plugin Test Vault; named plugin reload verified GCM 7.3.6.
- Installed with Controller 3.1.4 in the approximately 13,900-note test vault
  containing 2,550 synthetic conflicts: warm reminder matching fell from
  175.4/211.3 ms on the previous pair to 122.4/127.8 ms, with identical matching
  sets. These are hidden/background-window service timings, not click-to-paint
  measurements. Cold first use after GCM reload still read 13,897 sources and
  took 4.63 s; this patch does not remove initial source indexing.
- Installed actual Complete/status routes, duplicate deletion, unrelated edit,
  and reopening/recompletion passed on isolated synthetic notes. Initial 14
  projected alerts became zero after completion/deletion and remained zero;
  legitimate reopening restored alerts and recompletion removed them. Body and
  checklist content were preserved. This tests projection, not Apple delivery.
- Both plugin settings files remained byte-identical. Synthetic fixtures were
  retained in `_archive`; production notes/settings and external delivery were
  untouched. No physical-device installation was performed.

Minimum Obsidian: 1.10.0. Pair with Controller 3.1.4 for the full improvement.
No settings or schema migration is required. Tested in the test vault and ready
for the user's BRAT pull; not installed in production by this release process.
Physical-device acceptance remains separate; these tests do not establish
mobile/Windows latency or eliminate all possible sources of UI delay.
