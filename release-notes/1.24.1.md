# TPS Global Context Menu 1.24.1

GCM now leaves the upstream/non-TPS Notebook Navigator context menu entirely native.

## Changes

- Removed GCM's fallback injection from the global Obsidian Menu display patch for upstream Notebook Navigator targets.
- Obsidian `file-menu` and `files-menu` events now explicitly yield when the captured source is upstream Notebook Navigator.
- Menu reordering, deduplication, fold actions, and selection-recovery logic are skipped for upstream Navigator menus.
- The TPS Notebook Navigator integration remains active through its public menu extension API.
- Daily Note Home's read-only observation of upstream Navigator selection/open gestures remains available and does not intercept the menu.

## Compatibility and migration

- Minimum Obsidian version: 1.10.0.
- No settings or note schema changes are required.

## Validation

- Focused regressions verify that both upstream injection routes yield while the TPS public bridge retains exact targets, mixed file support, multi-selection, reload replacement, and cleanup.
- The complete declared test suite, TypeScript check, and separate production build were run against the final versioned artifact in the isolated Obsidian Plugin Test Vault.
- Production was not inspected or modified.

This release is tested in the isolated test vault and ready for the user's BRAT pull.
