# TPS Global Context Menu 1.39.0

This backward-compatible minor release makes a scheduled or due task a durable native Markdown record instead of leaving it as a synthetic line item.

## Changes

- In **Native Markdown records** mode, any confirmed mutation through GCM's canonical task writer that leaves an authored `scheduled` or `due` value promotes the exact current task into `_records/tasks/<tpsId>.md`.
- The source task line becomes a stable link to the record. Status, priority, dates, estimate, parents, recurrence, tags, completion metadata, and nested child content follow the existing guarded promotion contract.
- **Create task** now instantiates a tracked record when its accepted task has a scheduled value. The record opens directly after creation.
- Native task records bypass ordinary title-based auto-naming, preventing a rename/restore loop and the resulting Obsidian **Update links** prompt.
- Native mode no longer moves the scheduled line between Daily Notes. Changing `scheduled` on the record updates native Bases and TishOS projections without a second line location.
- Undated tasks stay lightweight and inline. Inherited Daily Note dates, empty date fields, bullets, and untouched existing tasks do not trigger background migration.
- Legacy mode is unchanged. The native record schema, settings, Bases, and public API versions are unchanged.

Minimum Obsidian: 1.10.0. Tested in the isolated test vault and ready for the user's BRAT pull into the TishOS Native POC.
