# TPS Global Context Menu 1.23.1

This patch fixes calendar task status changes that were incorrectly rejected as stale after unrelated metadata on the source task line changed.

## Changes

- A calendar task can be re-resolved by its unique authored `scheduled`, `start`, or `date` locator when its captured raw line is no longer byte-identical.
- Exact source-line and stable task-ID matches remain higher priority.
- Ambiguous or duplicated calendar locators, rescheduled tasks, changed checkbox tokens, and changed checkbox mappings still fail closed.
- No settings or note-data migration is required.

## Validation

- Focused task-line identity and calendar context-menu mutation regressions.
- Complete declared test suite and mandatory production build with test-vault runtime deployment.
- Minimum supported Obsidian version: 1.10.0.

Tested in the Obsidian Plugin Test Vault and ready for the user's BRAT pull. Production is not modified directly.
