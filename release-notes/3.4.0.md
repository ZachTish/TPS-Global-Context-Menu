# TPS Global Context Menu 3.4.0

Navigator property visibility can now be configured alongside each GCM custom property. Update both GCM 3.4.0 and TPS Notebook Navigator 6.5.0 to use the complete integration.

- Navigator's Properties configure button, section-menu action and property-key settings action open GCM Rules & fields → Custom fields.
- Each property has separate navigation-tree, populated note-list and file-menu visibility switches, labeled with the active Navigator profile.
- Navigator remains the only persistence owner for these existing flags. GCM provides their editing surface; there is no duplicate preference store, note mutation, migration, watcher or background automation.
- Explicit all-off entries survive saving, reload and property-catalog refresh. Previously normalization discarded them and catalog import could make them visible again.
- Stale-profile edits fail before changing settings. Failed saves restore the previous in-memory values and notify the user.
- Tags, ADOLink, PR Link and existing property definitions remain intact. This release does not apply the proposed taxonomy or remove Health definitions.

## Compatibility and limits

Backward-compatible minor feature. Minimum Obsidian: 1.10.0. GCM adds `api.ui.openCustomPropertySettings()`; Navigator adds `api.propertyVisibility` version 1 (`get`/`set`). Missing/older GCM retains Navigator's standalone modal; missing/older Navigator displays an explanatory message in GCM. Global Navigator visibility switches still apply. Existing catalog import defaults remain. A Navigator-only key needs a matching GCM custom-property definition to edit it through this screen. Physical iPhone acceptance remains outstanding.

## Validation

GCM: 1,240 declared-suite tests and 160 supplemental tests passed; TypeScript and final production build passed. Final separate production builds deployed to Obsidian Plugin Test Vault, followed by targeted plugin reloads. Installed UI QA exercised Navigator Configure property keys → GCM Custom properties, expanded Status, and changed visibility with the native toggles. Turning all surfaces off survived a Navigator reload. Original test-profile keys were restored and GCM definitions were unchanged. Runtime assets match the tested source artifacts byte for byte. No notes were changed and outbound automation stayed disabled.

Tested in the test vault and ready for the user's BRAT pull. Production installation is not part of this release. Update both plugins through BRAT; public release publication does not mean production has installed them.
