# TPS Global Context Menu 1.41.0

## Native records can live directly at the vault root

- Adds an explicit flat native-record layout alongside the existing kind-folder layout.
- Enter `/` as the native record destination and choose the flat layout to create stable-ID task, calendar, Health, workout, and asset records directly in the vault root.
- Existing records are not moved automatically. Existing settings default to the prior kind-folder behavior.
- Record schemas and the public native-record API remain compatible.
