# TPS Global Context Menu 1.20.0

## Daily Note work-session notes

- Time tracking now infers a task or note target from the active context instead of exposing separate start actions.
- Each running or manual session gets an editable workspace under the configured Daily Note heading, with top/bottom placement and a stable block identity.
- Pause, resume, stop, manual entries, cross-midnight sessions, and legacy-session repair preserve the same workspace without changing the tracked target.
- Mobile uses one in-flow timer dock with open-notes, pause/resume, and stop controls.

Existing settings and session records remain compatible. Minimum Obsidian version remains 1.10.0.

## Validation

- The complete declared test suite, focused Daily Note section and timer reliability coverage, TypeScript, and the mandatory production build passed.
- The final artifact was deployed only to the isolated test vault; production was not accessed.
