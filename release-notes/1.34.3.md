# TPS Global Context Menu 1.34.3

TPS Global Context Menu 1.34.3 makes Obsidian's strict Source mode a literal Markdown surface again.

## Source-mode integrity

- Inline-property chips and hidden TPS metadata replacements are disabled unless Obsidian explicitly identifies the editor as Live Preview.
- Completed-task hiding and its CSS selectors are scoped to Live Preview, so completed or migrated source lines cannot remain invisible after a mode change.
- Virtual Base panels are never mounted over strict Source mode.
- The rendered Linked context panel is removed in strict Source mode and restored when returning to Live Preview or Reading View.
- The scheduled-task continuation shortcut and automatic inline datetime normalization do not intercept literal Source-mode editing.
- Active Markdown mode changes rebuild editor decorations, task visibility, menus, and virtual Base surfaces from the current view state. The implementation no longer depends on Obsidian's optional `is-source-mode` DOM class.

## Compatibility and known limitations

- Backward-compatible patch with no new setting, public API, or note schema.
- Reading View and Live Preview retain their configured TPS rendering and task-hiding behavior. The change is intentionally limited to strict Source mode.
- Mode transitions are reconciled on Obsidian's normal editor rebuild and by GCM's bounded active-view mode check.
- Minimum supported Obsidian remains 1.10.0.
