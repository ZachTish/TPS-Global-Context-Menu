# TPS Global Context Menu 1.42.0

This backward-compatible minor release gives TPS plugins one shared, configurable definition of a template. A template may be identified through the Templater folder, a tag, or a property key/value rule, including containment for unresolved Templater expressions in root-level files.

TPS Calendar Base and TPS Notebook Navigator can consume the additive `templates` API version 1. Existing settings remain on Templater-folder behavior, and no file is moved or rewritten.

Minimum Obsidian: 1.10.0.
