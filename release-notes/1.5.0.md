# TPS Global Context Menu 1.5.0

This minor release makes the task move action easier to find and identifies the task's actual source note before a destination is chosen.

## User-visible changes

- The lower task-action section now begins with `Move task from <source note>...`.
- The source label uses GCM's canonical note display title, with the filename as its fallback, so task menus opened from embedded or virtualized surfaces still identify the containing note.

## Reliability and compatibility

- The destination picker and task-move mutation are unchanged. Moving within the current note still moves the complete task block to the note's end; cross-note moves retain destination-first safety and nested content; Daily Note sources retain their migrated scratchpad record.
- Selected-task move behavior is unchanged.
- Minimum supported Obsidian version: 1.10.0. Desktop and mobile are supported; no settings or data migration is required.
