# TPS Global Context Menu 10.0.0

This major release removes background note maintenance and the old inline collection API. Minimum Obsidian: 1.10.0.

## Immediate behavior changes
- No appearance rules/generated-property projection or automatic icon/color/hide-tag writes. Existing stored appearance and explicit edits remain.
- No navigation/change/startup timestamp, folder-path, title/filename, Daily Note population/repair, relationship/deleted-link maintenance or automatic archive sweep.
- No recurrence recovery, completion-generated successors, template propagation, recurrence edit/session watcher or generation operation store. Recurrence properties and explicit template-text edits remain. Status values replaces the old recurrence settings label; the unused template-folder control is removed.
- No periodic timer-to-note synchronization. Explicit start/stop/manual sessions, read-only timer recovery and elapsed display remain.
- No generic attachment-companion create/rename/delete maintenance. Explicit property/relink actions remain; moving an attachment can require explicit relinking.
- Task API v5 removes tasks.list and tasks.findByField plus the old filter/collection helpers. Retired relationship-repair adapters are removed. Navigator 9.0.0 removes its old consumers. No compatibility shim conceals these removals.

Existing notes, properties, IDs, credentials, databases, pairing and operational state are preserved. Saved old switches remain inert. No new scheduler, watcher, cache, mailbox, retry or repair layer is added. Native creation owns initial template preparation; explicit rename and mutations retain current-source, exclusion and identity checks.

## Validation
Final versioned declared suite: 1,655 reported passes, zero failures/skips. Retired implementation tests were replaced with absence checks; retained current-source/concurrency, identity-conflict, template, explicit status/date/property, creation, native rename, timer and display tests pass. The separate final TypeScript/production build deployed only to Obsidian Plugin Test Vault and the final 10.0.0 manifest reloaded.

Installed validation created one native synthetic task with a configured kind mapping and temporary Inbox root; explicit body/property/icon/color edits persisted. Obsidian's native Rename file command renamed it. Body and all properties remained byte-identical, including ID and appearance; the removed filename-to-title maintenance correctly did not rewrite the stored title. Settings were restored without saving, the original Navigation 20 tab restored, and the synthetic folder archived. Native settings inspection showed Status values, active/completed controls and the explicit message that completion does not create another note. The retired template-folder control was absent. No real settings or external automation were enabled.

Earlier installed retained-workflow checks exercised actual food logging, recipe search, workout set add/edit/remove, wrong-owner rejection, whole-note timers and manual finance edits with the relevant consumers enabled. Mocked provider/camera boundaries and physical iPhone limitations remain disclosed in their owning release notes.

Operation gates observed zero TPS maintenance writes for ten-minute settled idle, two-minute foreground typing, 20-note navigation, 100-file simulated Sync create/update bursts, settings, and Finance dashboard opening. Core saves and read-only Navigator/GCM work were attributed separately. Focused burst/unload tests cover removed callbacks and no-op work. These are test-vault results, not production telemetry.

Five foreground samples per group: warm reload before median/worst 6066.2/7142.1 ms; cleaned 6084.7/7143.5 ms; TPS disabled 6360.5/6755.1 ms. Long tasks: 14/15/10. Navigation before 897.2/1134.5 ms; cleaned 838.9/892.9 ms; disabled 427.3/529 ms. The stated median no-regression threshold passed. Sequential groups have startup variability; this is neither full-quit production startup evidence nor a claim of disabled-plugin parity. Physical iPhone acceptance is unverified.

## Rollout and rollback
Tested in the test vault and ready for the user's BRAT pull. Use Navigator 9.0.0 and the corresponding Controller/Health/Finance/AI/Linter cleanup versions together. Production was not installed or reloaded. Downgrading can reactivate preserved automation flags, state and old writers; stop owners and review state before rollback. Notes are not overwritten or restored automatically.
