# TPS Global Context Menu 3.6.10

Backward-compatible relationship-inspection performance fix. Minimum Obsidian remains **1.10.0**.

Child discovery no longer evaluates the child ignore rule before `hasParent` evaluates it again. That parent-resolution operation now shares one logical frontmatter value between its ignore check and stored-link resolution. Each new call still obtains current data; the shared value never reaches a mutating operation.

Hidden companions, native versus attachment routing, custom keys/aliases, ignored child and parent behavior, self-links, and stored-link access for explicit unlink retain their existing policies. No retained cache, index, hooks, settings, API version, schemas or migration change. One full candidate scan and necessary linked-parent checks remain.
