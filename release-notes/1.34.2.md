# TPS Global Context Menu 1.34.2

TPS Global Context Menu 1.34.2 keeps task rows resolvable when task text is edited beside inline tags or pasted from multiple lines.

## Task quick editor

- Typed and pasted hard line breaks are flattened to spaces as the draft changes. Long task text can still wrap visually, but a save always produces one Markdown task record.
- Inline hashtags, punctuation, configured properties, hidden TPS identity metadata, and block IDs remain attached to that record.
- Rendered inline hashtag links and inline-property widgets are normalized with the same metadata-aware title rules as the source Markdown. A successful save also stamps the current row with the confirmed line fingerprint, title, path, and line number, covering both the immediate refresh gap and the later host rerender.
- The editor copy now states that it edits one task line and that line breaks become spaces.

## Compatibility and known limitations

- Backward-compatible patch with no new setting, API, or note schema.
- The quick editor is intentionally line-scoped. Creating nested task or bullet blocks remains an operation for the note editor rather than this one-record form.
- Minimum supported Obsidian remains 1.10.0.
