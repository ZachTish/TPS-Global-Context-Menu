# TPS Global Context Menu 1.25.1

TPS Global Context Menu `1.25.1` removes the note-open race and work storm between the Tasks/Mentions navigation and Linked Context. The surfaces now share a deterministic mount lifecycle instead of repeatedly displacing and rebuilding one another.

## Fixes

- Mount Tasks/Mentions and top Linked Context inside one GCM-owned title surface, with navigation always before context across initial creation, metadata refreshes, and forced rebuilds.
- Render Linked Context off-DOM and commit only the latest request after rechecking the active file, view mode, settings, placement, and incoming-source revisions. Stale and failed candidates unload their Obsidian renderer components.
- Coalesce repeated same-key collection and rendering, cancel inactive-leaf and unload work, preserve the current panel until a replacement host is ready, and remount across Reading/Live Preview mode changes.
- Keep Live Preview Linked Context outside CodeMirror's editable `.cm-content`, while retaining a Reading-mode fallback for notes without an inline title or H1.
- Stop note-open Task reads and link/reference scans. The buttons remain available with stable neutral labels; Tasks load on click, and Mentions runs one complete deferred reference scan only after its popover is connected, including notes found only by unlinked text.

## Compatibility and migration

- No settings keys, defaults, public APIs, commands, or note schemas changed.
- Existing Linked Context placement and open-behavior choices continue to apply.
- Minimum supported Obsidian version remains `1.10.0`.

## Validation

- The 15 focused Linked Context interaction/service regressions passed, followed by TypeScript validation and the complete declared `npm test` suite.
- A separate production-mode build deployed the final `1.25.1` artifacts to the isolated test runtime; source and runtime artifacts matched byte for byte.
- In reloaded Obsidian 1.13.6, 25 forced header rebuilds retained one connected shared host, navigation bar, and Linked Context panel with stable host/panel identity. Sixteen rapid alternating note opens also ended with exactly one tracked panel and no pending render.
- Reading mode and Live Preview both kept navigation before Linked Context below the inline title. Live Preview mounted the shared host under `.cm-sizer`, with no GCM host or panel inside CodeMirror's editable `.cm-content`.
- QA used temporary in-memory settings only. The persisted plugin settings and note content were unchanged, and production was not modified.
