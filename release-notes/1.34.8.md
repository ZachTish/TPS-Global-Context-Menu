# TPS Global Context Menu 1.34.8

TPS Global Context Menu 1.34.8 removes empty Linked-context heading cards and reduces completed-task work during Live Preview scrolling.

## Linked context excerpts

- A heading link is omitted when its excerpt contains only whitespace, HTML comments, or a standalone block ID.
- Nested headings, text, lists, media, and other visible content still keep the excerpt.
- A heading or whole-note card containing only terminal tasks follows completed-task visibility as one card. Mixed cards remain present and hide only their terminal rows.
- The existing source order and stable card identity are unchanged.

## Live Preview performance

- Completed-task decorations rebuild when the document changes or the editor is reconfigured, not on cursor movement or viewport movement.
- CodeMirror virtual-line DOM replacement during scrolling is ignored by GCM's Live Preview observer.
- The reveal-control state is cached from the complete editor document, avoiding a second scan of every mounted `.cm-line` while preserving the existing Show completed behavior.

## Compatibility and known limitations

- Backward-compatible patch with no new setting, public API, note rewrite, or schema migration.
- Empty ordinary line links remain visible because the linked line itself is the requested context; the empty-content rule applies to heading excerpts.
- A terminal-only card is hidden only when completed-task hiding applies to that surface. Show completed reveals it in its original stable order.
- Minimum supported Obsidian remains 1.10.0.
