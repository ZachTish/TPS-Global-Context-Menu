# TPS Global Context Menu 1.25.2

This backward-compatible patch exposes GCM's existing Daily Note task-schedule inheritance decision through its public API so reminder consumers can honor the owning setting.

## What changed

- Daily Notes API v2 adds `getTaskSchedulePolicy(file)` with read-only `isDailyNote` and `inheritUnscheduled` results.
- The policy reuses GCM's configured Daily Note recognition and the existing **Inherit Daily Note date for unscheduled tasks** setting; no consumer needs to read private plugin state.
- GCM API lifecycle events now include `dailyNotesVersion`.
- TPS Controller 0.3.11 consumes this capability for task reminder evaluation.

## Compatibility and migration

- Minimum Obsidian version: 1.10.0.
- No settings, defaults, note schema, or data migration changed.
- Existing Daily Note task surfaces and API v1 methods remain compatible.
