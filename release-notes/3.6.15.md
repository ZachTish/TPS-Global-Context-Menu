# TPS Global Context Menu 3.6.15

The Daily Note date strip could open an unrelated archived note with the same date filename instead of offering to create the configured Daily Note. Navigation now uses the existing shared Daily Notes identity and configuration API, including for named legacy notes. This is a backward-compatible patch; no settings migration, public API version change, background repair or new state is introduced.

- Existing recognized Daily Notes open in their current location without reconciliation or a write.
- Date-strip visibility follows the shared classifier and configured mappings/exclusions.
- Core/Periodic configuration precedence comes from the existing owner.
- Confirmed creation is bound to the path displayed in the confirmation; changing configuration while the dialog is open cannot silently redirect it.
- Unresolved identity reports that indexing is pending rather than starting creation; observable canonical notes remain readable.

## Validation

Tested in Obsidian Plugin Test Vault with the consumer suite enabled and external automation disabled. 117 focused, 1,356 declared-suite and 197 supplemental checks passed, zero failures/skips. Seven of the eight new routing regressions failed before the correction. Tests execute the real manager with mocked API/UI boundaries; existing composed identity/creation suites exercise shared behavior. One hundred unchanged opens require zero manager-owned scans, source reads, writes and creation calls. TypeScript, separate normal build, Test deployment and named plugin reload passed; data.json remained byte-identical.

Foreground installed UI verified real Core-template creation, archived filename collision confirmation, cancellation, changed-destination rejection and a recognized legacy note opening in the originating leaf. The latter made no create/modify/process/rename calls; two fixture reads were recorded across the enabled consumers. A unique legacy body replaced a distinct anchor body in 31 ms in one warm sample. This is correctness evidence, not an overall performance benchmark. Four synthetic notes and the template were archived directly; source bytes, seven runtime configurations and prior navigation/window state were preserved. Temporary in-memory Core/NN options and the competing top-parent button toggle were restored; diagnostic hooks removed.

The earlier 3.6.14 repeated-template probe used a shared body marker. Its repeated navigation timings are provisional because they do not prove old-body replacement time; source and operation-count regressions remain valid. Future probes require distinct per-file content. Templater is absent, physical iPhone/cold-process/native-baseline parity and production acceptance remain unverified. This release does not remove the separate first native-record mutation identity scan or resolve all reported naming lag.

Minimum Obsidian: **1.10.0**. Tested artifacts are ready for the user's BRAT pull. Production was not inspected or deployed.
