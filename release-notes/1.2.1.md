# TPS Global Context Menu 1.2.1

Mobile note-title icons now survive delayed title remounts, and TPS List/Table task selection highlights only the exact source line that was selected.

## User-visible changes

- Live Preview and Reading mode title refreshes now reconcile the GCM title icon every time Obsidian remounts or replaces the inline-title element.
- Mobile-style inline titles outside the usual mode-specific wrapper receive the same title-icon treatment as desktop layouts.
- TPS Table, TPS List, Calendar, and Kanban task highlights now use their documented one-based task-line metadata exclusively; native Obsidian `data-line` remains zero-based.
- Long-pressing a TPS Table task synchronizes the Table row selection before the shared task menu opens, so an old selected row cannot remain highlighted beside the new active row.

## Reliability and compatibility

- Explicit source-path or line mismatches stop highlight resolution immediately instead of falling through to duplicate task-text matching.
- Missing line attributes no longer coerce to zero and accidentally match the first task in a note.
- The inline persistent-UI master switch still removes/prevents title icons, and strict Source mode still shows the literal filename without a GCM icon.
- Existing range and modifier multi-selection behavior remains unchanged.
- Minimum supported Obsidian version: 1.10.0.
- No settings or data migration is required.

## Validation

- Focused title/highlight/Table/Home suites: 81/81.
- Complete declared suite: 259/259.
- TypeScript validation and the required separate production-mode build passed; the final build reported the isolated test runtime unchanged.
- Obsidian 1.12.7 was reloaded with **Reload app without saving**.
- UI verification switched an icon-enabled note from Live Preview to Reading mode and exercised adjacent TPS List rows plus a synthetic two-row TPS Table task fixture. Each Table long-press opened the exact selected task menu, and the neighboring source line was not admitted by highlight resolution.
- The temporary inline-UI setting was restored to its original disabled value. The disposable task-table note and Base were moved directly to `_archive`.
- The final source artifacts are byte-identical to the isolated test-vault runtime.

## Known limitations

- The macOS test app cannot emulate Obsidian Mobile's native delayed title-node lifecycle exactly. The lifecycle and mobile-DOM fallbacks are regression-covered, but final on-device visual confirmation remains appropriate.
- Title icons remain intentionally unavailable when the `Show inline context menu` master switch is disabled or while a note is in strict Source mode.
