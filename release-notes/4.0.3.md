# TPS Global Context Menu 4.0.3

Folder-move choices no longer compare every folder with every other folder. The picker walks each folder path’s ancestors once and uses local membership checks to find leaves. This removes quadratic work when a vault has many folders.

- Preserves selectable folders, nearest-ancestor labels, locale ordering, current-folder checks and exact move destinations.
- Rebuilds choices from the current inventory each time; new and moved folders remain immediately visible.
- No persistent cache, watcher, timer, background work, new setting, schema or API. File-move and archive writers are unchanged.

Backward-compatible patch. Minimum Obsidian: **1.10.0**.

Validation: eight focused regressions pass; two operation-count checks fail before the fix. Coverage includes 1,500 sibling folders, a 25-request unchanged burst, sparse/prefix/trailing paths, Unicode, roots/duplicates, changed inventory, and the existing menu’s checked state and callback targets. The full declared suite passes 1,388 checks and the supplemental suite passes 209, with zero failures/skips. TypeScript, separate normal Test deployment and named plugin reload pass; seven recorded settings files are unchanged.

Installed method verification returns the same 2,669 choices/labels/order by serialized SHA-256. Separate instrumentation counts 7,253,920 prefix comparisons per call before, zero after; one inventory read remains. Seven uninstrumented synchronous calls measured 181–255 ms before and 15–19 ms after (medians 197/17 ms). Baseline was foreground; after was visible but unfocused. These are warm method-computation samples, not actual menu-paint/input latency or evidence of a whole-vault speedup. An unrelated test overlay prevented picker gestures. Physical iPhone, cold process startup and native-performance parity are not claimed. Diagnostic wrappers were restored and no notes were changed.

Tested in Obsidian Plugin Test Vault; ready for the user’s BRAT pull once published. Production installation and user/device acceptance remain separate.
