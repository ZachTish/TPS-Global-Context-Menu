# TPS Global Context Menu 1.10.2

## What changed

- TPS Table Selector cells now open their configured dropdown instead of allowing the table row or Base note-preview interceptor to open the containing note.
- Selector dropdowns use the shared property-option resolver and support configured options, vault-backed options, a custom value, and clearing with `(none)`.
- Task Status cells use the configured checkbox mappings rather than a separate inline selector value.
- Status changes run through GCM's canonical checkbox-mutation path, including completed-date, recurrence, checklist, note-status, timestamp, event, and overlay follow-ups.
- Before a task Status change, the configured status carrier and legacy `status` and `checkboxStatus` inline carriers are removed so reconciliation cannot undo the selected checkbox state.
- Click ownership is scoped to cells with a real editor. Title and other non-editable row cells retain their previous exact-line task editor or navigation behavior.

## Compatibility and migration

- This is a backward-compatible patch release.
- No settings or note-data migration is required.
- Existing Selector options and checkbox mappings remain authoritative.
- Minimum supported Obsidian version: 1.10.0.

## Known limitations

- Selector dropdown editing requires a matching configured Selector property. Non-editable or unconfigured cells intentionally keep the row's existing navigation behavior.
- Task Status choices follow configured checkbox mappings. Duplicate mappings can intentionally expose more than one checkbox marker with the same status label.
