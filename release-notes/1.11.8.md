# TPS Global Context Menu 1.11.8

This patch makes the optional desktop first-open heading collapse smaller, supported, and resilient to a note rename during its existing delay.

## What changed

- Replaced private `app.commands` discovery/execution with the public Obsidian `Editor.exec('foldAll')` API.
- Removed the manual fallback that scanned every line, unfolded the document, moved the cursor to each heading, toggled each fold, and restored cursor/scroll state.
- Retained the live `TFile` across the 700 ms delay and 1,200 ms retry, so title-sync renames no longer make the scheduled path stale.
- Made a thrown focus/fold request fail safely into the existing bounded retry.
- Corrected diagnostics to report that collapse was requested; the public editor command returns `void` and does not verify rendered fold state.

## Compatibility and migration

- This is a backward-compatible patch release.
- No command, setting, public API, note-data format, or user workflow was removed.
- The feature remains disabled by default and desktop-only. Mobile keeps Obsidian's native fold controls.
- The already-open guard, rapid-open coalescing, 700 ms delay, one 1,200 ms retry, and editor focus behavior are preserved.
- No settings or note-data migration is required.
- Minimum supported Obsidian version: 1.10.0.

## Measured effect

- The shipped heading-collapse service is 77 net lines smaller.
- The retired fallback-only route performed one private command-registry read, scanned every line, allocated a heading list, ran `unfoldAll`, ran one `toggleFold` per heading, and moved/restored cursor and scroll state.
- The final route performs one public `foldAll` dispatch with zero line, cursor, or scroll calls.
- The exact 1.11.7 delayed-path regression made zero fold calls after the file was renamed before 700 ms; 1.11.8 makes exactly one fold call against the live path.

## Validation

- The exact released 1.11.7 source passed its existing two focused checks but failed the new supported-API gate after one private `app.commands` read.
- The expanded 1.11.7 delayed-path regression failed when a `TFile` was renamed before the timer fired.
- The final implementation passes all 10 focused API, timing, retry, mobile, already-open, rapid-open, rename, error, and unload checks.
- The complete declared suite passes 543/543, including TypeScript and its production-mode test-vault build.
- The mandatory separate final production-mode build passed after the version and documentation update.
- In Obsidian 1.12.7, released 1.11.7 missed a synthetic note's first-open collapse when title sync renamed it, then collapsed it after close/reopen.
- The candidate collapsed the equivalent renamed fixture on its first open, preserved an intentionally expanded heading when switching between already-open tabs, and collapsed the existing 215-line Base Filter Lab guide. Nested headings, lists, and fenced code remained intact.
- Runtime-owned settings and recurrence state were restored/preserved after QA. Production was not accessed.

## Known limitation

Obsidian's supported `Editor.exec('foldAll')` API returns `void`; it cannot report whether CodeMirror's syntax tree was ready enough to fold a particular very large document. GCM therefore treats a non-throwing dispatch as best-effort and does not schedule an unconditional second fold that could collapse a heading the user intentionally reopened.
