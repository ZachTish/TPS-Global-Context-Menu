# TPS Global Context Menu 3.6.14

Daily Note creation repeated a whole-vault metadata-readiness scan at each reconciliation boundary even when GCM's existing readiness owner had already established that metadata and current-source generations were settled. Reconciliation now reuses that result. This backward-compatible performance correction is a patch release.

The identity candidate index, selected-file fresh reads, dirty-generation protection, configuration/template checks and collision guards remain authoritative. Unready or unavailable owner state retains the existing metadata gate. No new cache, watcher, timer, persisted setting, public API version, migration or automatic repair is added. Minimum Obsidian: **1.10.0**.

## Validation

- Four focused regressions cover 100 unchanged absent lookups, 100 existing lookups, newer source identity, edits during an in-flight read and unresolved metadata. The operation-count regression reproduced 101 enumerations before and requires one initial index enumeration after; existing-file lookups still make one current-source read each.
- 105 focused tests, 1,348 declared-suite tests and 197 supplemental tests passed; no test failures or skips. TypeScript and a separate production build passed and deployed to **Obsidian Plugin Test Vault**. Named plugin reload verified 3.6.14 and unchanged runtime data.json; the final documentation rebuild is byte-identical to the UI-tested artifacts.
- Actual foreground UI actions with the suite enabled: Navigator confirmation→templated creation, GCM date-strip confirmation→templated creation twice, body edit and existing-note reopening. Creation samples were **379/317/314 ms** versus **429/460/334 ms** before. Markdown-file enumerations before visible body were **2/1/1** versus **5/5/4**; metadata lookups were about **43k** versus **75–97k**. Each creation retained one create, one modify and two process calls. No measured long tasks. Times begin at trusted input and end after two frames containing the expected visible body, not compositor paint.
- Source assertions preserve authored titles, core template tokens' resolved values, body edits and template bytes. Six synthetic Daily Notes and two templates archived directly after verification; seven configurations, prior empty leaf and window size restored; instrumentation removed.

## Limits and handoff

Small warm desktop samples establish removed redundant work, not an overall/native/mobile speed guarantee. Safety preflight warmed identity lookup. Templater is not installed/enabled here; existing automated template coverage remains. No cold-process, physical iPhone or production claim is made. The two date-strip repeat dates changed after the baseline fixtures were archived; counts therefore provide stronger causal evidence than precise timing ratios.

A separate existing routing mismatch was reproduced: the GCM date strip's filename-only fallback can open an archived non-Daily note which the shared identity API excludes. That route is documented for a separate fix and is not changed by this release. No content was altered by that diagnostic open.

This release is tested in the test vault and ready for the user's **BRAT pull**. It is not evidence of production installation or user acceptance.
