# TPS Global Context Menu 1.21.0

## Linked context

- Adds an opt-in, read-only incoming-link panel at the top or bottom of a note.
- Ordinary-line links show only their source line; heading links show the complete nested heading section; frontmatter links show the complete source note.
- Source cards are bordered and dimmed until hover or focus. Activation can open the exact source in the same tab, a new tab, or Obsidian hover preview.
- Duplicate source ranges are collapsed, and source notes are never modified.

## Compatibility and validation

- Backward-compatible minor release with no note-data migration. The new settings default to disabled, bottom placement, and same-tab activation.
- Minimum supported Obsidian version: 1.10.0.
- Focused source-range regression tests, TypeScript, the full declared test suite, and the final production build passed in the isolated Obsidian Plugin Test Vault.
- Tested in the test vault and ready for a BRAT pull. Production was not accessed.
