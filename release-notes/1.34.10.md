# TPS Global Context Menu 1.34.10

TPS Global Context Menu 1.34.10 makes Linked-context ordering directly discoverable in the settings UI.

## Linked-context settings

- The full control group now appears under **Menus & surfaces → Linked context** instead of the unrelated Child notes workflow page.
- **Linked context order** offers **Source path A → Z** and **Source path Z → A** and stays editable while the panel is disabled.
- Enabling the panel reveals its placement and activation controls in the same section.
- Existing setting keys and values are reused, so the move requires no migration and does not reset a user's current order.

## Compatibility and known limitations

- Backward-compatible patch with no new setting key, default, public API, note rewrite, or sorting change.
- Ordering is intentionally source-path ascending or descending. Excerpts from one source always retain physical document order, and modification time is never used.
- Minimum supported Obsidian remains 1.10.0.
