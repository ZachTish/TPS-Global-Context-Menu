# TPS Global Context Menu 3.5.2

Clicking a note's title opens Edit Title with the entire current value selected, ready to replace by typing. Selection occurs once during initial focus. Subsequent caret placement, Save/Enter, Cancel, validation and title/filename ownership retain their existing behavior. Other text-property dialogs are unchanged. This is a backward-compatible patch with no user setting or data migration. Minimum Obsidian: 1.10.0.

Validation: all 1,240 declared-suite tests and 165 supplemental tests passed. TypeScript and the mandatory separate production build passed, with deployment and targeted reload only in Obsidian Plugin Test Vault. Installed QA invoked the note-title editor, verified focus and the full 0–18 selection range, typed a replacement, cancelled without changing the note, then reopened and saved a replacement with Enter. The synthetic fixture was archived directly. Physical iPhone acceptance remains unverified. No production artifacts or notes were changed.

Tested in the test vault and ready for the user's BRAT pull; production installation is separate.
