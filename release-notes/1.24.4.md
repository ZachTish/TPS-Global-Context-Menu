# TPS Global Context Menu 1.24.4

TPS Table now honors its unmatched-group placement and displays GCM's mapped workflow status for task rows.

## Changes

- Added **Items without a group** with **Top** and **Bottom** choices to TPS Table view settings.
- The unmatched group is placed independently of ascending or descending populated-group sorting. Existing views default to Bottom.
- Bare `status` on task rows resolves to GCM's checkbox-mapped workflow status, while non-task rows retain their authored note/line status.
- Explicit `task.status` continues to expose the same mapped workflow value, and relational status remains isolated for formulas and note data.

## Compatibility and migration

- Minimum Obsidian version: 1.10.0.
- No note schema or global plugin setting changes are required.
- Each TPS Table Base view stores its own unmatched placement choice.

## Validation

- Focused regressions cover Top/Bottom unmatched placement and mixed mapped-task/authored-row status grouping.
- The complete declared test suite, TypeScript check, and separate production build were run against the final versioned artifact in the isolated Obsidian Plugin Test Vault.
- Production was not inspected or modified.

This release is tested in the isolated test vault and ready for the user's BRAT pull.
