# TPS Global Context Menu 4.0.5

Native-record mode now keeps automatic file events out of the inactive legacy attachment-property index. Startup already skipped that service, but a folder or attachment rename/delete could reactivate full-vault discovery and queue ordinary Markdown rename bookkeeping behind it.

- Applies the existing architecture setting at each lifecycle event, preserving mode changes after registration.
- Skips legacy folder/source/companion handlers, pending-target bookkeeping and Canvas invalidation in native-record mode.
- Keeps recognized companion records excluded from ordinary note automation. Retains ordinary title refresh, configured title synchronization, link cleanup and native consumers.
- Leaves legacy mode’s storage, identity validation, conflict guards, current-source writes and retained history unchanged.
- Adds no cache, watcher, timer, retry, repair system, setting, migration or public API.

Backward-compatible patch; minimum Obsidian **1.10.0**.

Five added tests execute actual registered callbacks; four reproduced the defect before correction. Coverage includes 20-event bursts, companion exclusions, ordinary title/delete handling, legacy event dispatch and changing the selected architecture after registration. All **77 focused, 1,398 declared and 209 supplemental checks** pass with zero failures/skips. TypeScript, separate normal Test build/deploy and named reload pass. Legacy writes, conflicts and concurrent edits use real service tests with mocked host storage.

Installed first-use comparison after reload, using the same nested-folder fixture with all consumers enabled: raw vault reads **11,224 → 8**, legacy lifecycle handlers and queue entries **→ 0**, unused companion index remains uninitialized. Baseline legacy handlers completed in **3.4–3.5 seconds**, including discovery and serialized waits. Repeated folder moves, attachment renames and Markdown renames preserve all 17 fixture files, paths and seven settings files.

Installed file-manager deletion of a synthetic attachment and empty folder also passes with no legacy dispatch/index/queue work; other consumers still perform work. An initial low-level `vault.delete` call failed on an empty directory before the target lifecycle event (host adapter non-recursive removal); its fixture was preserved in `_archive`. Validation then used the normal file-manager trash route and the existing trash preference. Synthetic artifacts are archived or trashed; diagnostic hooks are removed.

Limits: visible but unfocused installed API samples, with instrumentation and explicit async settling. Core API return time does not show a consistent improvement (first folder move 114 ms before, 134 ms after); removed background work is the demonstrated benefit. These measurements do not establish blocked-UI time, foreground input latency, native-performance parity, cold-process startup or physical iPhone performance. Installed QA uses native-record mode; matching legacy companion mutations are covered offline. No production installation or user/device acceptance is implied.

Tested in Obsidian Plugin Test Vault; ready for the user’s BRAT pull once published. Production remains untouched.
