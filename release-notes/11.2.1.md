# TPS Global Context Menu 11.2.1

Fix the stale Properties block on an open note. The old structural refresh guard deferred indefinitely while a property button or body editor retained focus. A reproduced edit saved `kind: task` while the block still displayed `note` more than three minutes later.

The existing metadata callback now updates only mounted property blocks whose indexed values differ from their rendered values. Body offsets and unchanged metadata do not rebuild the block. Missing metadata is not treated as deletion; property removals, classification-dependent fields and multiple mounted copies are supported. Focused property buttons retain focus without scrolling; body editor state is untouched. General menu geometry keeps its typing guards. No settings, schema, writers, subscriptions, timers, scans or persistent caches are added. Minimum Obsidian remains 1.10.0.

Validation: 2,006 declared tests pass, no failures or skips, followed by a separate production-mode build and explicit test-vault deployment/reload. Focused tests cover changed/removed values, missing metadata, migration ownership, switched/detached/unrelated notes, multiple copies, focus and 1,000 unchanged events. Existing editor-write concurrency, selection/history and source-integrity tests remain passing. A pre-existing mocked event harness was extended with the new display callback after the initial full run identified its missing method; no check was skipped.

Installed desktop checks used a synthetic Inbox note and normal enabled consumers with Sync off. Native GCM Status edits immediately displayed complete/todo; changing Kind updated the visible field set. The two Status refreshes took 5.8 and 5.9 ms; next-frame timing from starting the property writer was 341 and 28 ms respectively, including native saving/indexing. A property edit while the body retained focus preserved the editor instance, body, focus and body-relative cursor offset; it reached the next frame in 15 ms. Reading mode also showed updated values. These are foreground samples, not a cross-device latency guarantee.

Ordinary native typing caused zero property-block renders. An installed burst of 1,000 unchanged target checks plus 1,000 unrelated checks took 1.8 ms with 1,000 direct metadata lookups, zero body/cached reads, scans, mutations or renders. This burst isolates the changed display owner; it is not a benchmark of every enabled plugin. Exact artifact digests accompany the public release. Production installation and physical iPhone acceptance are separate; this release is the user's BRAT handoff.
