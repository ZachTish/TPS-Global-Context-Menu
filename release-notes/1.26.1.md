# TPS Global Context Menu 1.26.1

TPS Global Context Menu `1.26.1` fixes note-open UI churn when Calendar, Tasks, Mentions, and Linked Context are enabled together.

## Root cause and fixes

- A reused Markdown view switched its navigation to the new file immediately but retained the previous file's interactive Linked Context until every replacement card finished rendering. The old-file panel is now removed before the new incoming-link scan begins.
- Repeated file-open and settle events rebuilt the bottom navigation even when its file, placement, settings, scheduled state, and registered actions were unchanged. Bottom navigation now caches both mounted and intentionally empty states and reconciles only when its signature changes or a real forced refresh is requested.
- The delayed file-open pass is non-forcing but still asks the surface manager to attach missing UI. This preserves late DOM readiness without tearing down an already-correct top or bottom row.
- Linked Context previously recomputed its full incoming-link revision after every asynchronously rendered card. Per-card checks are now constant-time, with one authoritative revision check at the commit boundary.
- A navigation build now passes its already-resolved child-note set into the deferred label refresh instead of repeating the vault-wide reverse-child enumeration.

## Compatibility and migration

- Calendar, Tasks, Mentions, and Linked Context remain independently configurable and may all be displayed at the same time.
- The three navigation visibility toggles remain default-on and are not required to avoid the glitch.
- No setting key/default, public API, command, or note schema changed.
- Minimum supported Obsidian version remains `1.10.0`.

## Validation

- Every self-contained GCM-owned declared test segment passed. Two cross-repository discovery checks that inspect the explicitly paused TPS Kanban source were not rerun.
- A separate final production-mode build passed, deployed the exact artifacts below to the test runtime, and matched that runtime byte-for-byte without changing its `data.json`.
- Obsidian `1.13.6` test-vault QA verified all four top/bottom navigation and Linked Context placement combinations, eight rapid A→B→A note transitions, Reading/Live Preview transitions, and hiding Calendar, Tasks, and Mentions while keeping Linked Context visible with no empty navigation row.
- Temporary settings were restored byte-for-byte and the four synthetic QA notes were moved from `Inbox` to `_archive`.
- Production was not accessed or modified.
