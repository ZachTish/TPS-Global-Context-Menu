Tested in Obsidian Plugin Test Vault and ready for the user's BRAT pull. This is an additive minor release; production installation is separate.

Property-key configuration now uses draft → Apply → review → Confirm update. Confirmation migrates matching Markdown frontmatter before saving the new mapping. This covers custom property keys, integration property names, created/modified timestamps, view mode, time tracking, task reveal state, and child-parent links.

Custom properties also provide Rename stored value for exact strings and list items. Replacing one manual option with one new option proposes the same migration. Adding/removing/reordering suggestions is explicitly configuration-only; ambiguous multiple renames require individual actions. Known GCM references, status classifications/checkbox mappings, Kind constraints, and shared integration/default key mappings follow the rename.

The review lists affected paths and conflicts. Scans show persistent progress, use bounded concurrent reads, and can be cancelled. Cancel, changed settings, or a stale preview writes nothing. Conflicting destination keys, duplicate/malformed relevant YAML, inherited merge properties, and unsafe source layouts block migration. Source-range edits preserve unrelated YAML, comments, line endings, and note bodies. Per-file source checks protect concurrent edits. A verified private recovery record supports rollback after partial failures and restoration from Advanced after interruption; completed migrations remove it.

Scope: all Markdown frontmatter, including templates and archived notes. Inline fields, prose, Base formulas, other plugins' configurations, core property-type metadata, and hard-coded record contracts are not rewritten. Values match exact strings without numeric/boolean coercion. Changing a filter criterion directly remains a selection change. Multiline value replacements and ambiguous YAML require manual editing. Other devices/plugins are not locked during migration.

Validation: 1,193 declared checks and 126 additional checks passed, including 26 focused migration tests covering source preservation, conflicts, cancellation, stale/new notes, failed writes/settings saves, recovery, cancellation during pending reads, inherited YAML, and shared mapping ownership. The separate production build deployed to the test vault and was reloaded. Actual settings UI QA cancelled a two-note preview without changes, then confirmed key and value renames across scalar/list fixtures, verified preserved bodies/comments/unrelated properties, updated manual options, and removed recovery storage. Original configuration was preserved; fixtures were archived. The confirmation layout was visually inspected.

Minimum Obsidian: 1.10.0. Desktop and mobile supported; physical iPhone acceptance remains pending. No production deployment was performed.
