# TPS Global Context Menu 6.0.1 — Smoother desktop typing and title display

GCM no longer serializes the full editor buffer on every keystroke to schedule a retired Markdown parent reconciler. It keeps the existing edit-time tracking used by typing guards and timestamp ownership. On desktop, the 900 ms sweep across open Markdown panes and rendered links is replaced by title refresh at layout readiness, file-open, active-leaf and layout events, and actual title metadata changes. A body-only metadata event with an unchanged cached title skips inline-title DOM work. Rendered links that GCM previously retitled update when their target title changes; author aliases and later edited link text are preserved. Mobile retains the 900 ms fallback for delayed title/icon remounts pending physical-device validation.

This is a backward-compatible performance and title-display fix. It does not change note content, settings, commands or the public API. Minimum supported Obsidian remains **1.10.0**. Other installed plugins and Obsidian core can still contribute to typing latency; this release does not establish production-device speed.

## Validation

- Focused operation-count tests: 1,000 editor changes make zero full-note `getValue()` calls, retired reconciliations or timers; desktop registers zero recurring title sweeps; title display initializes with inline menus disabled; 100 unchanged metadata events make zero title DOM lookups or rendered-link scans; an actual target-title change updates its rendered link.
- Full declared `npm test`: **1,481 passed, 0 failed**. Its build ran with `TPS_NO_DEPLOY=1` so the shared Test runtime remained available for concurrent QA.
- A separate `npm run build` passed TypeScript/esbuild and deployed byte-changed `main.js` and `manifest.json` to the Test vault. Source and installed runtime hashes match; `styles.css` was already identical. The GCM-only Test Settings toggle was used to reload the plugin. The settings registry still displayed version 6.0.0 until an app-level manifest refresh, so the installed `manifest.json` and matching bundle hash establish the deployed version.
- In the foreground Test window, switching from the TPS Finances tab back to `Inbox/TPS Typing Performance QA 2026-10-03.md` restored its inline frontmatter title, **TPS Typing Performance QA**, with inline menus disabled. The note body was left unchanged. Foreground post-change typing timings and physical-iPhone remount behavior have not been measured here.
