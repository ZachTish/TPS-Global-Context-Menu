# TPS Global Context Menu 1.34.6

TPS Global Context Menu 1.34.6 fixes the completed-task reveal control's interaction with Obsidian's Reading View virtualizer.

## Scroll and reveal stability

- **Show completed** is mounted directly on the Markdown view root as an absolute, zero-flow overlay. GCM no longer inserts the control into `.markdown-preview-sizer`, so it cannot add document height or change Obsidian's virtualized section geometry.
- The reveal-control refresh removes duplicate controls and performs idempotent text and accessibility-label updates. Its observer therefore no longer retriggers itself for unchanged UI.
- Linked context and task hiding were tested together. Top-placed Linked context, completed-task hiding, repeated page scrolling, and linked-source refreshes retain the current note section.

## Compatibility and known limitations

- Backward-compatible patch with no new setting, public API, note rewrite, or schema migration.
- The desktop reveal control remains at the top of the note rather than following the user down the document. Mobile retains its existing fixed bottom control.
- Minimum supported Obsidian remains 1.10.0.
