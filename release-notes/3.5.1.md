# TPS Global Context Menu 3.5.1

Navigator presentation and native-record inspection now reuse resolved property profiles across notes. This removes repeated resolution of every kind mapping inside each kind lookup. It is a backward-compatible performance patch; no settings, taxonomy, note migration, watcher or repair behavior changes.

Prepared mappings invalidate on actual settings-value changes, including nested in-place edits and migration-read mode. Public profiles, classifications and mapping dictionaries remain detached copies. Existing identity ambiguity, migration and ownership checks remain enforced.

Installed desktop test-vault benchmark with 26 synthetic two-level mappings and 1,466 operations:

| Operation | 3.5.0 | 3.5.1 |
| --- | ---: | ---: |
| Record inspection | 622.2 ms | 245.1 ms |
| Navigator protected-property lookup | 7,638.4 ms | 26.6 ms |

These are one before/after sample of the identified paths, not an overall-vault or iPhone speed guarantee. Controller 2.6.2 separately reduces notification audit costs; both updates are recommended for the measured lag.

Validation: 1,240 declared-suite tests plus 165 supplemental tests passed. TypeScript and the mandatory separate production build passed, deploying only to Obsidian Plugin Test Vault. Targeted final reload loaded 3.5.1. Temporary benchmark configuration was restored and runtime settings stayed byte-identical. No production artifacts, notes or settings were changed. Minimum Obsidian 1.10.0. Physical iPhone timing remains unverified.

Tested in the test vault and ready for the user's BRAT pull; production installation and user acceptance are separate.
