# TPS Global Context Menu 1.44.1

This backward-compatible patch makes the explicit **Create task** command match Native Markdown record semantics.

- In Native Markdown records mode, **Create task** now always creates a note-backed `kind: task` record, including undated tasks. The selected containing note receives a stable link and the record opens for editing.
- The native modal now says **Create task note**, explains the stable-link behavior, and presents the checkbox mapping as the task's initial status. Legacy mode continues to create a lightweight inline checkbox.
- Native creation has a stable `tpsId` even when Item History is disabled, keeping duplicate-looking lines resolvable and unlinked recovery records idempotent.
- Native/Legacy mode is revalidated at the atomic write boundary. Changing architecture while the modal is open fails without writing the wrong representation.
- Promotion and navigation failures now report the committed state precisely. The staged checkbox is preserved when linking cannot be confirmed, a created recovery record is identified, and an open failure no longer masquerades as creation failure.

Minimum Obsidian: 1.10.0. Existing settings, task records, inline checkboxes, command IDs, Bases, and public APIs require no migration.
