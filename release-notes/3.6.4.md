# TPS Global Context Menu 3.6.4

Keep unchanged custom-property controls mounted in native hover and Base previews. This backward-compatible patch removes redundant refresh work after note edits. Minimum Obsidian remains **1.10.0**; no settings, API or data migration.

## Changes

- Metadata changes own property updates. The existing DOM observer handles preview mounting and path changes through one coalesced callback.
- Remove duplicate create/modify listeners and the 250/900 ms forced-refresh bursts that rebuilt every open panel after unrelated body edits.
- Reuse a panel only when both its file path and semantic frontmatter are unchanged. Include classification/visibility dependencies even when those fields are not themselves displayed; exclude parser position metadata.
- Preserve explicit settings/visibility refreshes and late preview mounting, including nested prebuilt wrappers.

No new cache, watcher, retry, repair pass or automatic note changes.

- `npm run prepretest`: **184 passed**, zero failures/skips.

Refresh invocations fell from 11/16/16 to 1/1/2 respectively; the second property refresh reused the mounted panel.

The installed probes exercise the real preview bridge with synthetic DOM hosts, not a physical iPhone gesture. They measure redundant work, not general interaction latency or the broader native-performance target. Other startup, navigation and creation work remains under investigation.
