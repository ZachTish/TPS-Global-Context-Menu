# TPS Global Context Menu 1.23.0

## New

- Free-text task tag editors show filtered existing vault-tag suggestions beneath the input.
- A tap or click fills the field from a suggestion. Enter saves exactly the typed value and does not implicitly accept a suggestion.

## Scope and compatibility

- The behavior is shared by task context menus, TPS List, and TPS Table on desktop and mobile.
- New tags remain valid free text. Suggestions are case-insensitively deduplicated and capped at twelve visible matches.
- No settings or note schema changed. Minimum supported Obsidian version is 1.10.0.
