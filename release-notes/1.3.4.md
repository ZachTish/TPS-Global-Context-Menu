# TPS Global Context Menu 1.3.4

This follow-up patch uses Obsidian Mobile's native keyboard event height so task editing remains above the iOS software keyboard even when both browser viewport APIs stay full-height.

## User-visible changes

- Opening the task quick editor on a phone now moves the complete card, including Open in note, Cancel, and Save, into the native unobscured area as the keyboard opens.
- The same native boundary is available to every shared keyboard-aware TPS overlay and GCM modal.
- The boundary remains in place while the keyboard closes and is removed after the native `keyboardDidHide` event.

## Reliability and compatibility

- GCM reads both Capacitor's direct `event.keyboardHeight` payload and a `CustomEvent.detail.keyboardHeight` payload for compatibility.
- Native keyboard height is merged with the existing layout/visual viewport intersection by choosing the smaller usable height. If the webview already resized or panned, GCM does not subtract the keyboard twice.
- Timed reposition passes still cover delayed iOS keyboard animation frames, and every native listener is removed with its overlay or the plugin-wide viewport contract.
- Minimum supported Obsidian version: 1.10.0.
- No settings or data migration is required.

## Validation

- Focused task-editor and mobile-overlay suites: 48/48.
- Complete declared isolated release-snapshot suite: 269/269, including TypeScript and its build-only production bundle.
- A separate production-mode build from that exact snapshot deployed `main.js` and `manifest.json` to the test runtime; `styles.css` and `styles-ui.css` were already byte-identical.
- Obsidian 1.12.7 was reloaded in `Obsidian Plugin Test Vault` with `Reload app without saving`. The existing Plugin QA TPS List rendered both task rows, clicking `Synthetic open task #qa` displayed the exact-line editor with Open in note, Cancel, and Save, and Cancel closed it without changing the QA note.
- All four final source artifacts match the test runtime byte-for-byte. Runtime-owned `data.json` remained in place and was not rewritten by deployment.

## Known limitations

- The isolated macOS test app cannot display Obsidian Mobile's native Capacitor keyboard. Automated regressions dispatch both supported native payload shapes and reproduce the all-viewport-values-stale iOS geometry; final device confirmation remains separate.
